## Suggested Content for Figure 1.4.1

**Instructional purpose:**  
Give readers one clean visual reference connecting commonly encountered electronic elements to their schematic symbols before transistor operation and IC logic are introduced.

**Filename:** `1.4.1 - Major Electronic Devices and Their Schematic Symbols.png`  
**Intended width:** 900 px in Markdown  
**Recommended aspect ratio:** 16:9

### Overall layout

Use a clean engineering-reference layout with two horizontal rows or a balanced grid. Each item should show:

1. device/component name;
2. exact schematic symbol;
3. one very short role label where useful.

### Required elements

Include:

- resistor;
- capacitor;
- inductor;
- diode;
- NPN BJT;
- PNP BJT;
- enhancement-mode NMOS;
- enhancement-mode PMOS;
- DC voltage source;
- circuit reference / ground.

A connector/interface symbol may be included only if it does not overcrowd the figure.

### Required labels

Use concise labels only:

- Resistor
- Capacitor
- Inductor
- Diode
- NPN BJT
- PNP BJT
- NMOS
- PMOS
- Voltage source
- Circuit reference

Optional one- or two-word role labels:

- Limit / set current
- Store charge
- Store magnetic energy
- Directional conduction
- Switch / amplify
- Supply
- Reference

### Technical requirements

- Use conventional schematic symbols with controlled vector geometry.
- Use a conventional inductor coil symbol consistent with the selected symbol family.
- BJT emitter arrows must distinguish NPN and PNP correctly.
- NMOS and PMOS symbols must be clearly distinguishable.
- Do not imply that one symbol shows the exact internal physical shape of the device.
- Do not embed package outlines such as QFN/BGA around the transistor symbols.

### Visual style

- Clean engineering-textbook reference sheet.
- White or very light neutral background.
- Restrained technical colors; black/dark gray symbols preferred.
- Consistent symbol size and line weight.
- No photorealistic components.
- No overall title embedded in the artwork.

### Prohibited or misleading elements

- Do not use incorrect transistor-arrow directions.
- Do not mix IEC and ANSI variants randomly within the same symbol family.
- Do not label circuit reference automatically as protective Earth.
- Do not show a fixed numeric voltage for the source.
- Do not turn the figure into a detailed circuit schematic.

### Technical verification sources

- earlier Chapter 1 instructional materials, for book terminology and component sequence.
- Standard introductory circuit-symbol conventions.
- Rao R. Tummala, *Fundamentals of Microsystems Packaging*, Chapter 2, for diode/BJT/MOSF device context.

These sources are for technical verification only. The figure composition must be independently created for this OER.

Create an original reference layout using standard schematic symbols. Do not copy the distinctive arrangement of a textbook or online symbol chart.
