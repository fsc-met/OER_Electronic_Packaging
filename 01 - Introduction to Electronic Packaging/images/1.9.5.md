## Suggested Content for Figure 1.9.5

**Instructional purpose:**  
Help readers visually recognize common IC package families and, most importantly, distinguish their **external connection styles**.

The figure should compare representative:

- DIP;
- SOIC;
- QFP;
- QFN;
- BGA;
- CSP / WLCSP.

The teaching emphasis is not package history or exact dimensions. It is:

> **different package terminal styles create different PCB assembly, routing, inspection, thermal, and rework implications**

**Filename:**  
`1.9.5 - Common IC Package Families and External Connections.png`

**Intended width:** 900 px in Markdown

**Recommended aspect ratio:** 16:9

### Required technical relationships

The comparison must make clear that:

- DIP is through-hole;
- SOIC and QFP are leaded surface-mount packages;
- QFN is leadless surface-mount;
- BGA uses underside area-array solder balls;
- CSP/WLCSP is physically compact;
- package family describes external package form, not necessarily the internal die interconnection method;
- mounting method is a separate concept from package family.
