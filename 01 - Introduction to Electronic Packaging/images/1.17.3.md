## Suggested Content for Figure 1.17.3

**Figure title for authoring/reference only:**  
`From Transistor Scaling to System-Level Scaling`

**Instructional purpose:**  
Show students why advanced packaging has become increasingly important as semiconductor progress becomes less dependent on simple transistor shrink.

The figure should communicate:

> **Modern semiconductor progress increasingly combines transistor innovation with advanced packaging and system-level integration.**

It must also preserve the technical distinction:

> **Advanced packaging complements transistor scaling; it does not replace continued transistor innovation.**

**Filename:**  
`1.17.3 - From Transistor Scaling to System-Level Scaling.png`

**Intended Markdown width:** 900 px

**Recommended source-art size:** at least 1800 × 950 px

**Recommended aspect ratio:** approximately 16:9

---

### Overall layout

Use a restrained **two-part comparison / convergence diagram**, not a poster.

Recommended structure:

#### Left — traditional scaling emphasis

Show a simplified progression:

`Smaller transistors`
→
`More transistors on a monolithic die`
→
`Higher chip capability`

Keep this side visually simple.

#### Right — modern combined strategy

Show two parallel contributors:

`Continued transistor innovation`

and

`Advanced packaging / system integration`

These should converge into:

`Higher system capability`

The advanced-packaging branch should visually include several of the following:

- multiple dies / chiplets;
- heterogeneous integration;
- advanced substrate or interposer;
- 2.5D integration;
- 3D stacking;
- dense die-to-die interconnection;
- memory near logic;
- advanced cooling / heat spreading.

Do not include every technology if the figure becomes crowded.

---

### Central comparison message

The main visual contrast should be:

> **Earlier emphasis:** improve mainly by shrinking and integrating more transistors on one die.

versus:

> **Modern strategy:** continue transistor innovation **and** combine specialized dies, dense interconnects, advanced packaging, power delivery, and cooling at the system level.

This should be visible from the diagram itself, without requiring long text.

---

### Traditional-scaling side

Recommended objects:

- one simple transistor icon;
- one monolithic die;
- one arrow showing increasing transistor density;
- one concise label:
  - `Transistor scaling`

Optional small note:

- `historically dominant improvement path`

Do not imply this path has ended.

Do not use a red X or “obsolete” symbol.

---

### Modern combined-strategy side

Recommended visual:

A package or substrate containing:

- one logic die;
- one or two chiplets;
- optional memory stacks or memory dies;
- advanced substrate / interposer;
- short die-to-die links;
- heat spreader or cooling path.

Possible concise labels:

- `Advanced transistor`
- `Chiplets / multiple dies`
- `Heterogeneous integration`
- `2.5D / 3D integration`
- `Dense interconnect`
- `Advanced thermal management`

Use only the labels needed for clarity.

---

### Convergence / output

Both major contributors should feed a final output:

- `Higher system capability`

Optional secondary outputs:

- `Performance`
- `Power efficiency`
- `Integration density`
- `Functional flexibility`

Do not imply every advanced package improves every metric simultaneously.

If these outputs are shown, use concise wording and equal visual weight.

---

### Important packaging relationships to show

Where possible, visually reinforce:

- different dies can be optimized for different functions;
- multiple dies communicate through package-level interconnects;
- advanced substrates or interposers support dense routing;
- higher integration increases thermal-management importance;
- package and system architecture now contribute directly to performance improvement.

The figure should not be a detailed chiplet-architecture diagram.

---

### Recommended visual language

- white background;
- restrained textbook palette;
- monolithic die: dark neutral;
- chiplets/dies: muted blue / teal variations;
- substrate/interposer: muted green or tan;
- interconnects: thin gold/copper lines;
- thermal path: restrained warm arrows;
- system output: neutral navy;
- concise sans-serif labels;
- simple arrows;
- no gradients unless subtle;
- no branded commercial package.

---

### Prohibited or misleading elements

Do not:

- imply transistor scaling has stopped completely;
- imply advanced packaging replaces transistor innovation;
- show one monolithic-die path with a red X or failure symbol;
- imply chiplets are always superior to monolithic dies;
- imply all systems require 2.5D or 3D integration;
- imply all products require liquid cooling;
- imply packaging alone guarantees continued Moore's-law scaling;
- present SiP, chiplets, 2.5D, and 3D as interchangeable terms;
- overload the figure with every advanced-packaging technology;
- turn the figure into a vendor roadmap;
- use product logos or company-specific package images;
- use long paragraphs;
- embed the external figure number or caption.

---

### Optional simplified composition

A very clean alternative is:

`Transistor innovation`
↘

`Advanced packaging + system integration`
↗

→ `Higher system capability`

with small technical illustrations embedded within the two input branches.

This is preferable if a more detailed two-column comparison becomes too crowded.

---

### Technical verification sources

Use:

- current Section 1.17 text and technical notes;
- imec CMOS-scaling / system-technology co-optimization framing;
- TSMC and Intel leading-edge transistor-architecture information;
- Tummala packaging references;
- current advanced-packaging references already used by the MET406 OER.

The public figure must remain vendor-neutral and independently composed.
