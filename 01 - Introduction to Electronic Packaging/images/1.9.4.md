## Suggested Content for Figure 1.9.4

**Instructional purpose:**  
Introduce **wafer-level packaging (WLP)** and **wafer-level chip-scale packaging (WLCSP)** at recognition level.

The figure should show that key packaging-related structures can be formed **before singulation**, while die locations are still processed in wafer or reconstituted-wafer format.

The main teaching message is:

> **packaging features formed at wafer level -> redistribution / bump structures -> singulation -> compact packaged device**

The figure may briefly introduce fan-out packaging but must keep it awareness-level.

**Filename:**  
`1.9.4 - Wafer Level and Chip Scale Packaging Concept.png`

**Intended width:** 900 px in Markdown

**Recommended aspect ratio:** 16:9

---

### Overall layout

Use a left-to-right conceptual flow with two related tracks:

#### Main track – WLCSP

1. processed wafer with die locations;
2. dielectric / redistribution layer (RDL);
3. UBM / bump pads;
4. solder balls or bumps;
5. singulation;
6. compact packaged device close to die size.

#### Optional small lower track – fan-out concept

Show one die embedded in reconstituted mold/carrier with redistribution extending beyond original die footprint.

Keep this secondary.

---

### Main track details

#### Wafer with die locations

Show:

- circular wafer;
- repeated die grid.

Required label:

- `Wafer with completed dies`

#### Redistribution layer

Show a zoomed cross-section of one die location.

Required labels:

- `RDL`
- `Die I/O pads`

#### UBM / bump interface

Show:

- metal interface stack below or above bump site.

#### Solder balls / bumps

Show:

- array of external solder balls or bumps.

Required label:

#### Singulation

Show:

- dicing/singulation line;

Required label:

- `Singulation`

Show:

- package outline close to die outline;
- no large conventional leadframe/substrate.

Required label:

- `WLCSP`

- `Package size close to die size`

### Optional fan-out inset

If included, show:

- external solder balls beyond die edge.

Required label:

- `Fan-out concept`

Optional note:

- `Redistribution extends beyond die footprint`

Do not turn this into a detailed fan-out manufacturing flow.

---

### Required technical relationships

The figure must correctly show that:

- some packaging operations occur before wafer singulation;
- RDL changes connection locations / pitch;
- UBM supports bump/ball formation;
- WLCSP can be close to die size;
- wafer-level packaging does not necessarily require a conventional package substrate;
- fan-out allows redistribution beyond the original die area;
- WLCSP / fan-out are packaging concepts, not PCB fabrication.

---

### Spatial relationships

- Keep wafer context visually obvious at the start.
- Use a zoom-in to one die location for RDL/bump details.
- Keep final singulated package physically close in size to the original die.
- Keep fan-out inset smaller and secondary.

### Prohibited or misleading elements

Do not:

- show WLCSP as a conventional leadframe package;
- imply WLP always uses one exact material stack;
- imply every WLP is fan-out;
- imply fan-out is the same as standard WLCSP;
- show PCB traces inside the wafer-level package;
- include detailed redistribution-layer manufacturing recipes;
- overstate reliability or thermal advantages.
