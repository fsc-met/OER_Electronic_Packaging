## Suggested Content for Figure 1.6.6

**Figure Title:** CMOS AND Function Using NAND and Inverter

**Purpose:**  
Show how a non-inverting AND function can be constructed from a NAND stage followed by an inverter.

**Suggested Content:**  
Create a clean left-to-right functional circuit:

`A, B → CMOS NAND stage → intermediate node X → CMOS inverter → output Y`

Required labels:

- input $A$;
- input $B$;
- `NAND`;
- intermediate node $X$;
- `Inverter`;
- output $Y$.

Show the equations:

- $X=\overline{A\cdot B}$;
- $Y=\overline{X}=A\cdot B$.

The NAND block may use a simplified transistor-level drawing or a clearly labeled gate/block representation, but the final inverter should be recognizable as the CMOS inverter already introduced in Section 1.6.3.

**Style Requirements:**
- uncluttered left-to-right flow;
- clearly separate the NAND stage from the inverter stage;
- no detailed repetition of all inverter operating states;
- no embedded figure number or overall title.
