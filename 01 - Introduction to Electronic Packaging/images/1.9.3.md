## Suggested Content for Figure 1.9.3

**Instructional purpose:**  
Show the physical construction of a representative **flip-chip IC package** and contrast its interconnection path with wire bonding.

The main teaching message is:

> **face-down die -> bumps / copper pillars -> package substrate -> external terminals**

The figure should make clear that flip-chip uses direct area-array die-to-substrate connections and that **underfill may be used**, but is not universal in every flip-chip implementation.

**Filename:**  
`1.9.3 - Flip Chip IC Package Construction.png`

**Intended width:** 900 px in Markdown

**Recommended aspect ratio:** 16:9

---

### Overall layout

Use one clean conceptual cross-section.

Required major layers from top to bottom:

1. semiconductor die, face-down;
2. solder bumps or copper pillars;
3. optional underfill around the bump region;
4. package substrate with internal routing;
5. external package terminals such as solder balls or lands.

Do not automatically make the external package a BGA unless clearly labeled as a representative example.

---

### Required objects

#### Face-down semiconductor die

Show:

- active side facing downward;
- connection pads/bump sites on underside.

Required label:

- `Face-down die`

Optional label:

- `Active surface`

#### Bumps or copper pillars

Show an array of direct interconnections under the die.

Required label:

- `Solder bumps / copper pillars`

These should be clearly individual vertical connections, not wire loops.

#### Underfill

Show material between die and substrate surrounding bumps.

Required label:

- `Underfill (where used)`

The phrase `where used` is important.

Do not imply underfill is universal.

#### Package substrate

Show:

- several routing layers or simplified traces;
- vias if useful;
- die-side pads above;
- external-terminal side below.

Required label:

- `Package substrate`

Optional label:

- `Redistribution / routing`

#### External package terminals

Use either:

- solder balls;
- lands;
- another generic terminal style.

Required label:

- `External terminals`

If solder balls are shown, note that this is a **representative BGA-like external interface**, not a requirement of flip-chip.

---

### Required technical relationships

The figure must correctly show that:

- the die active surface faces the package substrate;
- bumps/pillars directly connect die pads to substrate pads;
- the interconnect path is physically shorter than typical wire-bond loops;
- the substrate redistributes fine-pitch die connections to larger external terminal pitch;
- underfill supports the joint region where used;
- external package terminals remain separate from die bumps;
- flip-chip describes an internal die interconnection method, not one unique package family.

---

### Optional comparison inset

If space permits, include a very small side inset:

`Wire bond: longer loop` vs `Flip-chip: direct bump`

This is optional and should not dominate the figure.

---

### Spatial relationships

- Die at top, face-down.
- Bumps immediately below die.
- Underfill around bumps.
- Substrate directly below.
- External terminals below substrate.
- Keep vertical hierarchy visually obvious.

---

### Color restrictions

Suggested:

- die: gray / blue-gray;
- bumps/pillars: metallic gold / copper;
- underfill: translucent pale blue / neutral;
- substrate: muted green / brown;
- routing: metallic gold;
- external solder balls: metallic gray.

---

### Suggested visual style

- clean cross-sectional engineering illustration;
- flat or restrained isometric;
- no photorealism;
- no brand-specific package;
- concise labels;
- no overall figure title/caption inside artwork.

---

### Prohibited or misleading elements

Do not:

- show the die face-up;
- add wire bonds as the primary path;
- imply all flip-chip packages use BGA terminals;
- imply underfill is mandatory in every case;
- show bumps as PCB solder joints;
- show a PCB instead of a package substrate;
- show a package lid unless it contributes to a clear secondary thermal concept.
