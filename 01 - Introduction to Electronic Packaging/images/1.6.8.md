**Figure Title:** From Logic Gates to a Half-Adder

**Purpose:**  
Show how basic logic gates can be combined to create a useful functional circuit.

**Suggested Content:**  
Create a clean functional block diagram of a **half-adder**.

- Show two inputs: $A$ and $B$.
- Branch both inputs to:
  - an **XOR** gate that produces **SUM (S)**;
  - an **AND** gate that produces **CARRY (C)**.
- Label the outputs clearly.
- Include:
  - $S=A\oplus B$;
  - $C=A\cdot B$.
- Optionally include a small note that a half-adder has no carry-in.
- Optionally include:
  - half-adder → full adder → multi-bit adder.

**Style Requirements:**
- textbook style;
- uncluttered layout;
- white background;
- clear wiring and branching;
- no figure number inside the image.
