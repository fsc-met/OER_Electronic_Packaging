## Suggested Content for Figure 2.13.1

**Figure title for authoring/reference only:**  
`What a PCB Fabrication Release Package Contains`

### Instructional Purpose

Show that a bare-board fabrication release is **not one drawing or one CAD export**. It is a coordinated manufacturing definition made from several complementary information sets that must all describe the same intended PCB.

This figure supports Section 2.13.2 immediately after the table that introduces the major information sets in a release package.

The figure should help MET readers answer:

> **What information does the PCB fabricator actually need from engineering before the board can be built?**

### Central Teaching Message

> **A PCB fabrication release is a coordinated set of geometry, construction, electrical-intent, requirement, and revision information. All of it must describe the same bare board and belong to the same controlled release.**

The figure should make it visually obvious that no single item—fabrication drawing, Gerber/copper data, drill data, stack-up, or netlist—by itself defines the entire manufacturing intent.

### Overall Layout

Use a **single integrated information-flow diagram**, not a poster and not a collection of screenshots.

Recommended organization:

1. Three restrained information groups occupy the left and center of the figure.
2. Each group contains simple labeled document/data tiles.
3. All groups converge on one central or lower-middle box labeled:
   - `Controlled bare-board fabrication release`
4. One clear arrow leads from that controlled release to:
   - `PCB fabricator / CAM`
5. A small control cue near the convergence point should state:
   - `Same board`
   - `Same released revision`

Suggested information grouping:

#### Group A — Geometry
- `Fabrication drawing`
- `Copper / layer data`
- `Drill data`
- `Rout / profile data`

#### Group B — Construction and requirements
- `Stack-up definition`
- `Controlled notes / callouts`

The controlled-notes tile may use concise subordinate text such as:
- material;
- surface finish;
- tolerances;
- controlled impedance when required.

#### Group C — Electrical intent and control
- `Netlist / electrical-test data`
- `Revision / release information`

The exact visual arrangement may use three columns, three horizontal bands, or grouped cards around a central release package. The central relationship must remain visually dominant.

### Required Objects and Labels

The artwork must include all of the following as readable labels:

- `Copper / layer data`

- `Netlist / electrical-test data`
- `Controlled notes / callouts`
- `Revision / release information`
- `Controlled bare-board fabrication release`
- `PCB fabricator / CAM`

At least one concise cue must reinforce synchronized control:

- `Same board`
- `Same released revision`

Optional small subordinate labels inside `Controlled notes / callouts`:

- `Material`
- `Surface finish`
- `Tolerances`
- `Controlled impedance, when required`

Do not add assembly bill of materials, component placement, stencil/paste data, or soldering instructions.

### Required Technical Relationships

The figure must communicate these relationships correctly:

1. **Fabrication drawing is only one part of the release.**
2. **Stack-up information controls layered construction and must agree with other released requirements.**
3. **Copper/layer data define imaged conductive geometry.**
4. **Drill data define hole-related manufacturing information.**
5. **Rout/profile data define board outline, slots, cutouts, and other routed geometry.**
6. **Netlist/electrical-test data communicate intended electrical connectivity for open/short verification.**
7. **Controlled notes/callouts carry requirements not fully represented by geometry.**
8. **Revision/release information controls which data belong together.**
9. All information sets converge into **one controlled bare-board fabrication release**.
10. The fabricator/CAM function receives the **controlled package**, not a collection of unrelated or contradictory files.

The figure must **not** imply that every information set must always be a physically separate file. The section explicitly allows coordinated multi-file releases and more integrated digital manufacturing-data exchange.

### Spatial / Geometry Requirements

- Use clean orthogonal or gently curved connector lines.
- Arrows should converge toward the controlled-release box without crossing through labels.
- Keep all text inside safe margins.
- Do not use many small paper icons that become illegible at 900 px.
- Each information tile should have comparable visual weight.
- The `Controlled bare-board fabrication release` box should be visually stronger than the individual tiles, but not oversized.
- The `PCB fabricator / CAM` box should sit downstream of the release package.
- The `Same board / Same released revision` cue should sit near the convergence or release box rather than floating far away.
- Avoid arrows from individual tiles directly to the fabricator if that makes the release look uncontrolled; their relationship should first converge through the controlled package.

### Color / Style Guidance

Follow the established EPAC figure language:

- explicit white background;
- clean flat vector style;
- restrained engineering colors;
- dark navy/charcoal text and connector lines;
- pale blue-gray or very light neutral document tiles;
- one restrained accent color for the controlled-release box;
- no gradients unless extremely subtle and technically useful;
- no shadows or decorative 3D effects;
- consistent sans-serif typography;
- moderate line weights;
- high contrast at 900 px.

Color must not carry meaning alone. Group names and labels must remain sufficient in grayscale.

### Scope Boundaries

Keep the figure limited to **bare-board fabrication release information**.

Do **not** add:

- component bill of materials;
- pick-and-place data;
- stencil or solder-paste data;
- assembly drawings;
- soldering process steps;
- detailed DFM limits;
- detailed Gerber/IPC-2581 comparison;
- detailed standards-family content;
- fabrication-process sequence;
- quality-inspection workflow after fabrication.

Those concepts either belong later in the book or are assigned to Figures 2.13.2 and 2.13.3.
