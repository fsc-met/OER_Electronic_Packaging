# Figure 2.9.3 - Where Typical PCB Fabrication Capabilities and Tolerances Act

## Instructional Purpose

This figure should help readers connect the numerical capability/tolerance summary in Section 2.9.13 to the **physical PCB features on which those values act**.

The central teaching point is:

> **PCB fabrication capability is not one number. Different manufacturing tolerances act on different parts of the board geometry.**

The figure should make it immediately clear where the following categories act:

- trace width and spacing;
- mechanical drill and hole position;
- annular ring;
- solder-mask opening/web;
- copper-to-edge clearance;
- routed board-profile tolerance;
- board thickness;
- via aspect ratio;
- plated-hole wall copper;
- layer-to-layer registration;
- bow/twist as a whole-board flatness requirement.

This is a **location-and-scale map**, not a replacement for the full table in Section 2.9.13.

The figure should reinforce that the values shown are typical mainstream rigid-FR-4 engineering references, not universal supplier-independent limits.

## Recommended Composition

Use a clean **three-zone engineering figure**.

### Zone A - Large top view: local XY-plane fabrication capabilities

Occupy approximately the left **55-60%** of the figure.

Show one simplified rigid PCB region in top view with:

- several copper traces;
- two adjacent traces with a clear spacing gap;
- one plated through-hole/via pad;
- one nearby mounting/mechanical hole;
- solder-mask openings around several pads;
- a narrow solder-mask web between two adjacent openings;
- one routed board edge;
- one copper feature close to that routed edge;
- one dashed nominal board-outline line and one actual/routed edge line to illustrate profile tolerance.

This top view should be used to locate the following capability/tolerance items:

1. **Trace width**
2. **Trace spacing**
3. **Mechanical drill diameter**
4. **Hole positional tolerance**
5. **Annular ring**
6. **Solder-mask opening allowance**
7. **Minimum solder-mask web**
8. **Outer copper-to-edge clearance**
9. **Routed profile tolerance**

Do not show every value in long prose. Use concise labels with a short typical-value line.

### Zone B - Large cross-section: Z-direction and multilayer capabilities

Occupy approximately the right **35-40%** of the figure.

Show a simplified multilayer PCB cross-section with:

- top copper;
- solder mask;
- dielectric/core/prepreg layers;
- at least two inner copper layers;
- one plated through-hole;
- one nonconnected inner layer with clearance;
- one intentionally slightly shifted inner copper feature to visualize registration;
- board top and bottom surfaces.

Use this view to locate:

1. **Board thickness**
2. **Via aspect ratio**
3. **Plated-hole wall copper**
4. **Layer-to-layer registration**
5. **Inner copper/plane-to-edge clearance** if space allows

The cross-section should remain conceptually accurate and should not become a detailed stack-up drawing.

### Zone C - Small whole-board side-view inset: flatness

Use a small inset, preferably across the lower-right or lower-center area.

Show:

- one nominally flat board reference line;
- one gently bowed board profile;
- one simple double-arrow or percentage callout.

Purpose:

- locate **bow/twist** as a whole-board requirement rather than a local feature dimension.

Do not show the mechanics of why bow/warpage occurs; Section 2.10 handles that.

## Required Technical Relationships

The final artwork must preserve all of the following:

### Trace / spacing

- trace width dimension must span the conductor itself;
- trace spacing dimension must span the clear gap between adjacent copper features;
- do not dimension center-to-center spacing.

### Drill / hole position

- mechanical drill dimension must refer to the hole diameter;
- hole positional tolerance must be shown as displacement of the hole center relative to a nominal/design center;
- do not confuse diameter tolerance with position tolerance.

### Annular ring

- annular ring dimension must run from hole edge to pad edge;
- it must not run from center to pad edge;
- nominal annular-ring geometry should be consistent with Figure 2.9.2.

### Solder mask

- mask opening must be larger than or aligned around the exposed copper pad as intended;
- mask-opening allowance should represent edge-to-edge offset;
- mask web must be the strip of mask between adjacent openings, not copper spacing.

### Copper-to-edge / profile

- copper-to-edge clearance must run from copper edge to routed board edge;
- profile tolerance must refer to the board outline itself;
- outer-copper and inner-copper examples should not be confused.

### Board thickness / aspect ratio

- board thickness dimension must run from finished top surface to finished bottom surface;
- aspect ratio must be visually tied to board thickness and hole diameter;
- do not imply that minimum drill size can be judged independently of board thickness.

### Hole-wall copper

- wall copper must be drawn as a thin plated layer around the through-hole;
- its thickness should be exaggerated for visibility and explicitly labeled as exaggerated if needed.

### Registration

- registration should be shown as relative position among layers/features;
- do not draw it as simple copper thickness variation.

### Bow/twist

- the inset should show whole-board flatness;
- do not imply that bow/twist is a local pad or hole tolerance.

## Geometry and Annotation Requirements

### Dimension arrows

Use conventional engineering-style dimension arrows.

Every dimension should terminate at the actual feature boundaries it describes.

Examples:

- trace width: copper edge to copper edge;
- trace spacing: adjacent copper edge to adjacent copper edge;
- annular ring: hole edge to pad edge;
- board thickness: finished top to finished bottom;
- copper-to-edge: copper edge to routed board edge.

### Nominal versus actual geometry

For positional/profile tolerance:

- use a thin dashed line for nominal/reference geometry;
- use a solid line for actual/possible manufactured geometry;
- clearly label nominal and actual only where necessary.

Avoid making the actual geometry appear like a defect or failure.

### Scale

The figure is **not to scale**.

This must be visually acceptable because:

- 20 μm plating cannot be visible at the same scale as a 1.6 mm board;
- 0.10 mm web/trace spacing cannot be shown at exact scale beside the overall PCB.

Where dimension visibility requires exaggeration, use a small note:

`geometry / thickness exaggerated for clarity`
