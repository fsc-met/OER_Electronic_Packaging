# 3.15 - Applied DFM Checklist

Section 3.14 explained how design-rule checking (DRC), broader design-for-manufacturability (DFM) review, supplier findings, and controlled release work together. This section converts the Chapter 3 material into a practical **pre-release DFM checklist**.

A useful checklist should not be a collection of disconnected "magic numbers."

It should answer three questions for each design feature:

> **What requirement applies? -> Does the design satisfy it with adequate manufacturing margin? -> If not, what must be changed, verified, or documented before release?**

The governing requirement should be identified before the item is marked `Pass`. It may come from:

- product or system requirements;
- component/package recommendations;
- the selected PCB fabricator;
- the selected assembler;
- inspection, test, rework, or service equipment;
- applicable standards and internal engineering rules.

> **Check the design against the actual selected manufacturing and product requirements, not only against a generic rule-of-thumb table.**

---

## 3.15.1 - How to Use the Checklist

For each checklist item:

1. identify the **governing requirement or capability source**;
2. inspect the current PCB/PCBA design and release data;
3. record the result;
4. resolve open findings;
5. rerun affected checks after any relevant design change.

A simple review status system is:

| Status | Meaning |
|---|---|
| **Pass** | The item has been checked against the applicable requirement and is acceptable |
| **Review** | The item is unresolved, below preferred margin, outside a rule, or waiting for supplier/engineering confirmation |
| **N/A** | The item does not apply to this design, with the reason recorded |

`Review` does not always mean that the design is wrong. It means that the item is not yet ready to be treated as closed.

The checklist below is organized by **engineering function** so that a reviewer can connect each item to the manufacturing activity it affects.

A practical review order is:

> **Fabrication -> Assembly -> Inspection/Test -> Rework/Service -> Tooling/Handling -> Release**

This order is convenient for review, but the categories interact. A change made for one category may reopen another.

## 3.15.2 - Fabrication Checklist

Fabrication review asks whether the bare-board geometry can be produced with adequate process margin.

| Check | What to verify | Typical response if unresolved |
|---|---|---|
| Trace width and copper spacing | Local minimum width/spacing is within the selected fabricator's capability; narrow neck-downs are intentional | Widen/increase spacing or confirm a controlled tighter process |
| Pads and land geometry | Copper lands are compatible with the component/package and selected assembly process | Correct the footprint or use the package/process-specific recommendation |
| THT holes and vias | Hole/via geometry is within drill, plating, aspect-ratio, and registration capability | Increase geometry, change the via structure, or use a verified advanced process |
| Annular-ring margin | Nominal ring provides margin for normal drill/registration variation | Increase pad diameter or change hole/via geometry |
| Via-in-pad | Any via in a solderable pad is intentional and uses a suitable process | Move it, tent/mask it where appropriate, or specify the required fill/planarization/plating process |
| Copper near the board edge | Copper has adequate margin from routed/scored/separated edges | Move copper inward or verify the selected profiling process |
| Copper robustness | No unintended slivers, fragile webs, severe local neck-downs, or unnecessary acute interior wedges | Remove/widen/re-route the weak local geometry |
| Solder-mask openings | Openings expose the intended solderable area and include adequate registration margin | Adjust expansion/overlap or use a process/package-appropriate mask strategy |
| Solder-mask web | Fine-pitch mask dams are manufacturable where separate dams are required | Increase web, merge openings, or use a verified finer mask process |
| Via mask treatment | Tented, untented, plugged/filled, and plated-over intent is unambiguous | Correct fabrication data/notes so the supplier cannot misinterpret the via treatment |

A clean DRC result supports this review, but it is not enough unless the rules match the intended fabrication process.

## 3.15.3 - Assembly Checklist

Assembly review asks whether the component geometry and assembly data allow parts to be placed, oriented, soldered, and handled as intended.

| Check | What to verify | Typical response if unresolved |
|---|---|---|
| Correct footprint | Package, pin numbering, pad count, body geometry, and land pattern match the intended component | Correct the library footprint before release |
| Placement data | X-Y location, centroid/origin, rotation, side, and reference designator match the PCB layout | Correct/regenerate component-placement data |
| Polarity and pin 1 | Polarized/oriented components have clear, consistent machine and human references | Correct orientation data and useful board markings |
| Component spacing | Courtyard/body spacing allows placement and intended inspection/rework access | Increase local spacing or verify the selected assembly/rework process |
| Component-to-edge placement | Parts are not unnecessarily exposed to routing, depanelization, conveyor, or handling risk | Move the part inward or confirm the actual panel/handling method |
| Tall/heavy components | Height, mass, overhang, shadowing, heating, handling, and local mechanical risk have been reviewed | Relocate/orient the part or plan process support intentionally |
| Land-pattern suitability | Termination-to-land geometry is appropriate for the package and assembly process | Use the component manufacturer's or another validated package/process-specific land-pattern guidance |
| Placement symmetry | Small chip components are centered and pad/copper asymmetry is not creating avoidable tombstoning risk | Correct placement or local pad/copper geometry |

Consistent orientation is helpful **where practical**, especially for polarized or repeated parts, but it should not be treated as a universal rule when another orientation is required by routing, thermal, mechanical, or inspection needs.

## 3.15.4 - Inspection and Test Checklist

Inspection and test review asks whether the planned verification methods can actually reach or observe the features they are expected to check.

| Check | What to verify | Typical response if unresolved |
|---|---|---|
| Optical line of sight | Important visible joints and placement features can be seen by the intended optical/manual inspection method | Reposition obstructing geometry or change the inspection strategy |
| Hidden solder joints | BGA, QFN, bottom-terminated, or otherwise hidden joints have an appropriate inspection approach where required | Plan X-ray or another suitable method rather than assuming optical access |
| Test-point access | Required electrical nodes have physical probe access for the intended test method | Add/move test points or revise the test strategy |
| Connector-based test | Required signals are actually available at an accessible connector if connector probing is planned | Add the required access or use another test method |
| Marking support | Reference designators, polarity/pin-1 marks, connector labels, and test-point labels support inspection and troubleshooting | Move/simplify/clarify markings |

Needing X-ray inspection for a package with hidden solder joints is **not automatically a DFM defect**. The important question is whether the inspection method is appropriate for the package and production requirements.

---

## 3.15.5 - Rework and Service Checklist

Rework and service review asks whether likely correction, replacement, and maintenance actions can be performed without excessive collateral risk.

| Check | What to verify | Typical response if unresolved |
|---|---|---|
| Tool approach | Hot-air, soldering-iron, tweezer, probe, or other required tool has a practical approach path | Increase local access or plan specialized tooling intentionally |
| Removal path | The component can be gripped/lifted without colliding with nearby parts | Increase spacing or revise neighboring placement |
| Neighbor thermal exposure | Rework heating will not unnecessarily expose vulnerable nearby components | Increase spacing, shielding opportunity, or revise placement |
| Replaceable parts | Fuses, batteries, connectors, modules, or other intended replaceable items are reachable | Relocate the item or revise the service strategy |
| Connector access | Mating/unmating action and cable approach have usable space | Add clearance or change connector orientation/location |
| Fastener access | Required screws/fasteners can be reached with the intended tool | Add tool approach space or revise the mechanical arrangement |

Serviceability is product dependent. A disposable or sealed product does not need the same field-service access as a maintained industrial system.

---

## 3.15.6 - Tooling and Handling Checklist

Tooling and handling review asks whether the board can be transported, aligned, supported, separated, and handled through the selected manufacturing process.

| Check | What to verify | Typical response if unresolved |
|---|---|---|
| Panel/rail strategy | Small or awkward boards have suitable temporary panel/rail geometry where needed | Add/modify rails or panel arrangement with the supplier |
| Depanelization method | V-score, tab routing, mouse bites, or another method matches the board outline and break requirements | Change separation method or local panel geometry |
| Break-region keep-out | Components, copper, and fragile features are protected from separation stress | Increase local keep-out or move the break feature |
| Global fiducials | Panel/board-level optical references meet the selected assembly equipment's needs | Add/reposition fiducials |
| Local fiducials | Extra local references are provided only where the selected precision-placement process requires them | Add or omit based on actual equipment/process need |
| Tooling/alignment holes | Mechanical registration features are provided where fixtures/equipment require them | Add/verify hole size and pattern |
| Conveyor/clamp access | Edge rails/handling regions are free of interfering components or overhangs | Add rail cutout/space or revise placement/orientation |
| Board support | Bottom-side components do not block all practical support locations | Relocate parts or confirm a custom support strategy |
| Repeated-board orientation | Panel orientation and assembly data remain unambiguous even if boards are rotated | Correct fiducials/orientation references/data |

Panel features should be confirmed with the actual fabricator and assembler rather than copied from a generic template.

## 3.15.7 - Release Checklist

Release review asks whether the design and its supporting data are ready to leave engineering control.

| Check | What to verify | Typical response if unresolved |
|---|---|---|
| DRC complete | Configured rules were run and open violations were resolved or formally dispositioned | Correct the design/rules and rerun DRC |
| Broader DFM/DFA review complete | Fabrication, assembly, inspection/test, rework, tooling, and handling items were reviewed | Complete the missing functional review |
| Supplier findings resolved | Fabricator/assembler findings have an explicit engineering disposition | Accept, revise, clarify, or document an authorized exception |
| Changes rechecked | Any affected outputs were regenerated and relevant checks rerun after changes | Regenerate/recheck before closure |
| Revision consistency | PCB, BOM, placement data, drawings/notes, and other applicable artifacts describe the same approved product definition/revision | Remove/replace stale artifacts |
| Release package ready | Required files are complete, unambiguous, approved, and appropriate for the intended supplier/process | Correct the package before release |

A release should remain blocked if a critical checklist item is unresolved or if the governing requirement is unknown.

## 3.15.8 - Representative Chapter Review Values

The values below are **engineering-scale reminders used in this chapter**, not universal release limits.

They help a reviewer recognize when a feature deserves closer attention.

| Topic | Representative chapter value | How to use it |
|---|---:|---|
| Ordinary component-to-component spacing | about **0.5 mm** | General SMT review scale |
| Preferred local spacing where rework access matters | about **1.0 mm** | Useful rework planning scale |
| Extra access near connectors, tall parts, or fine-pitch ICs | about **2.0 mm or more** | Review tool/inspection access |
| General component-to-board-edge planning | about **2.5 mm (0.10 in)** | Review handling/depanelization margin |
| Tall/heavy component edge planning | about **3.0 mm or more** | Requires stronger local review |
| THT lead-to-finished-hole diametral allowance | about **+0.15 to +0.30 mm** | Starting planning range; verify component/supplier rule |
| Annular ring | about **0.15 mm common reference; 0.20-0.25 mm preferred planning range** | Compare with selected fabrication capability |
| Solder-mask positive expansion | about **0.05-0.10 mm per side** | Conventional planning scale; tighter/1:1 processes exist |
| Solder-mask web | about **0.10 mm** | Common teaching reference; supplier/process dependent |
| Legend-to-solderable-feature clearance | about **0.10-0.15 mm** | Conventional planning range |
| Legend text / line | about **1.0 mm text height / 0.15 mm line width** | Conservative mainstream planning references |
| Assembly process rail | about **5 mm** | Common current example, not universal |
| Panel fiducial target | about **1.0 mm exposed copper** | Common current example |
| Tooling-hole scale | roughly **2-3 mm** | Equipment/supplier dependent |
| Routed-array profile spacing | about **1.6-2.0 mm** | Current supplier example for cutter access |

A reviewer should not convert this table into a universal pass/fail standard.

For production release:

> **Use the selected component, fabricator, assembler, tooling, inspection, test, and product requirements.**

## 3.15.9 - Applied Checklist Example

Assume a pre-release review finds the following conditions.

| Observation | Checklist judgment | Reason / response |
|---|---|---|
| Neighboring SMT bodies are 0.80 mm apart | **Review** | Above the 0.5 mm general review scale but below the 1.0 mm preferred rework scale; check actual tool/access need |
| 0.50 mm THT lead uses a 0.55 mm finished hole | **Review / revise** | Only +0.05 mm diametral allowance, below the chapter's +0.15 to +0.30 mm planning range |
| Nominal annular ring is 0.10 mm | **Review / revise** | Below the chapter's 0.15 mm common reference; verify actual supplier capability or increase pad size |
| Fine-pitch mask web is 0.06 mm | **Review** | Process-sensitive and below the chapter's common 0.10 mm teaching reference |
| BGA solder joints are hidden from optical inspection, but X-ray is included in the inspection plan | **Pass if process requirements are satisfied** | Hidden joints are inherent to the package; appropriate X-ray is not automatically a DFM failure |
| BOM is Revision B while PCB and placement data are Revision C | **Block release** | The release package does not describe one approved product definition/revision |

The purpose of the checklist is not to force every item into a simple good/bad label.

It is to identify:

> **what is acceptable, what requires more margin, what requires supplier confirmation, and what must be corrected before release.**

---

## Section Takeaway

The main ideas from this section are:

- a useful DFM checklist is organized around manufacturing functions, not arbitrary numbers;
- every checklist item should be tied to a governing requirement, capability, or product need;
- fabrication review covers copper, holes/vias, annular rings, board edges, solder mask, and fragile geometry;
- assembly review covers footprints, placement/orientation data, polarity, spacing, edge risk, height/mass, and land patterns;
- inspection/test review covers visibility, hidden-joint strategy, probe access, and useful markings;
- rework/service review covers tool approach, removal path, neighboring exposure, replaceable parts, connectors, and fasteners;
- tooling/handling review covers panels, separation, fiducials, tooling holes, conveyors, support, and orientation;
- release review covers DRC, broader DFM/DFA, supplier findings, rechecking, revision consistency, and package completeness;
- representative chapter values are review aids, not universal signoff rules;
- open or unknown critical items should be resolved before release.
