# Figure 3.9.3 Suggested Content Specification

## Figure title for authoring/reference only
**Untented and Tented Via Solder-Mask Treatments**

## Instructional purpose
Compare an untented/exposed via with a tented via and clearly distinguish solder-mask tenting from structural via filling and plated-over via-in-pad fabrication.

## Central teaching message
Tenting describes solder-mask coverage intent. It does not by itself guarantee complete hole sealing and is not the same as resin-filled, planarized, plated-over via-in-pad construction.

## Canonical PNG filename
`3.9.3 - Untented and Tented Via Solder-Mask Treatments.png`

## Intended mdBook display width
`900`

## Recommended canvas size / aspect ratio
- Recommended: **2000 × 1200 px**, approximately **5:3**.

## Overall layout
Use a **two-panel matched cross-section**:

1. **Untented / exposed via**
2. **Tented via**

Use identical via/board geometry so only the solder-mask treatment changes.

Add one compact distinction note:
`Tenting ≠ structural via fill / plated-over via-in-pad`

Do not create a third full panel for filled/capped via-in-pad.

## Required objects and labels
Objects:
- PCB substrate;
- top via pad;
- plated through-hole barrel;
- open bore;
- solder-mask layer;
- mask opening in untented case;
- mask coverage over via region in tented case.

Required labels:
- `Untented / exposed via`
- `Tented via`
- `Solder mask`
- `Via pad`
- `Plated via barrel`
- `Open bore`
- `Mask opening`
- `Mask covers via region`
- `Tenting is not structural via fill/cap`

Optional:
- `Complete closure depends on via size and process`

## Required technical relationships
Untented:
- intentional mask opening over via region;
- via/pad remains exposed at top.

Tented:
- no intended mask opening over the via;
- mask extends across the via region;
- bore/barrel underneath remains recognizable;
- do not depict bulk structural resin fill;
- do not depict a planar copper cap.

Do not imply tenting guarantees complete sealing.

## Spatial / geometry requirements
- Same board thickness and via dimensions in both panels.
- Cross-sections at equal scale.
- Mask layer thin relative to board thickness.
- Clear mask opening on left.
- Clear mask coverage on right.
- Enough whitespace for leaders.

## Color / style guidance
- Explicit white background.
- Board substrate: muted neutral/green.
- Copper/plating: muted copper/orange.
- Solder mask: distinct muted green.
- Bore: white/light.
- No structural fill/cap colors because those are out of scope.
- Flat, clean EPAC textbook style.

## Scope boundaries
Do not teach via aspect ratio, annular-ring design, detailed plugging chemistry, solder paste/reflow, or repeat Figure 3.7.4. Filled/plated-over via-in-pad appears only as a contrast note.

## Technical-verification basis
Current Section 3.9 and verified fabrication guidance establish:
- untented vias use a mask opening;
- tented vias omit the intended opening so mask covers the via region;
- complete closure depends on via size/process;
- suppliers distinguish tenting from plugging/filling;
- structural filled/planarized/plated-over via-in-pad is a separate process introduced in Section 3.7.
