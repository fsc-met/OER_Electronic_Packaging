## Suggested Content for Figure 3.4.2

**Figure title for authoring/reference only:**  
`Board-Edge, Height, and Rework Placement Considerations`

### Instructional purpose

Show how **physical placement space** around components affects:

- board-edge handling and depanelization;
- optical inspection visibility;
- physical access for rework tools.

This figure supports Sections 3.4.3 and 3.4.4 by turning three related physical-access concerns into one compact visual comparison.

The figure should not teach detailed spacing rules; it should help readers recognize **why physical clearance and local access matter** before Section 3.5 introduces more systematic spacing values.

### Central teaching message

> **Component placement must leave room not only for the component, but also for board handling, inspection, and rework.**

The figure should also communicate:

> **Tall or densely packed components can create obstruction even when the electrical layout is correct.**

### Overall layout

Use a **two-column good-versus-poor comparison**, with each side containing three vertically aligned zones.

#### Left column — Manufacturing-friendly placement

Show:

1. **Board edge**
   - small component set back from the routed edge;
   - visible free space between component body and edge;
   - no numerical dimension required.

2. **Tall-part inspection**
   - tall component positioned so a nearby small SMT component remains visible to an AOI line-of-sight or camera symbol.

3. **Rework access**
   - enough open space for a simplified hot-air nozzle, tweezers, or soldering-iron tip to approach a component without contacting neighboring parts.

#### Right column — Avoidable DFM problems

Show:

1. **Edge crowding**
   - component body close to board edge;
   - optional depanelization/routing zone symbol near edge.

2. **AOI obstruction**
   - tall component physically blocks the line-of-sight to a nearby small component or solder joint.

3. **Dense placement**
   - neighboring components leave little or no room for a rework tool.

This comparison should visually teach one common concept:

> **Physical access and clearance are manufacturing resources.**

### Required technical relationships

The final figure must correctly communicate:

1. Board-edge clearance provides space for manufacturing/handling processes; it is not merely unused board area.
2. The figure should not imply one universal edge-distance requirement.
3. A tall component can obstruct optical inspection of a smaller nearby component or solder joint depending on viewing geometry.
4. Tall components do not automatically cause an inspection problem; the issue is the actual line-of-sight/access relationship.
5. Rework access depends on physical tool approach, not simply component-to-component center spacing.
6. Dense placement can make repair difficult even if the original automated assembly can place the parts.
7. The figure should not imply that all tall components must be grouped together.
8. The figure should not imply that all boards use AOI from one fixed global direction; the viewing arrows are conceptual.
9. The figure should not imply that rework always uses hot air; the tool is illustrative.

### Spatial / geometry requirements

- Use simplified PCB geometry, not a realistic board photograph.
- Keep the board edge clearly visible in both columns.
- The problematic edge component should remain on the board; do not draw it hanging unrealistically off the edge unless deliberately illustrating an overhang.
- The tall component must be visibly taller than the small SMT part in the inspection zone.
- AOI line-of-sight should be a simple dashed cone or pair of rays.
- On the problematic side, the obstruction must be geometrically obvious: the tall component should intersect the viewing path.
- In the rework zone, the preferred tool path should fit without colliding with neighboring components.
- In the problematic zone, neighboring components should visibly block the tool path.
- Use enough whitespace that the three zones remain distinguishable at 900 px.
- Keep outer margins approximately 60-80 px.
