## Suggested Content for Figure 3.11.2

### Figure title for authoring/reference only

`Visible and Hidden Solder Joints for Optical and X-Ray Inspection`

### Instructional purpose

Show why **package geometry determines inspection visibility**.

The figure should compare:

1. an externally visible leaded solder joint;
2. a QFN package with important underside solder regions hidden by the package body;
3. a BGA package with solder balls hidden beneath the package.

The visual should explain why optical inspection is appropriate for exposed features while X-ray is a legitimate inspection method for hidden solder interfaces.

### Central teaching message

> **Inspection method should match the physical location of the solder joint. Hidden QFN and BGA solder interfaces may legitimately require X-ray; that requirement is not automatically poor DFM.**

### Canonical PNG filename

`3.11.2 - Visible and Hidden Solder Joints for Optical and X-Ray Inspection.png`

### Intended mdBook display width

`900 px`

### Recommended canvas size / aspect ratio

- Authoring canvas: approximately `1800 x 1050 px`.
- Recommended aspect ratio: approximately `12:7` to `16:9`.
- Three side-by-side cross-section panels are recommended.

### Overall layout

Use **three simplified package cross-sections** in one horizontal sequence:

1. `Exposed lead`
2. `QFN`
3. `BGA`

Each panel should show:

- PCB;
- copper pad(s);
- package body;
- solder interface;
- optical visibility status.

The QFN and BGA panels should also include a simplified X-ray path/beam concept.

Keep the geometry schematic and educational rather than manufacturing-photorealistic.

### Required objects and labels

#### Panel 1 — Exposed leaded package

Show:

- PCB substrate;
- exposed surface pad;
- gull-wing or similar external lead;
- visible solder fillet / joint;
- label `Visible solder joint`;
- optical eye/camera or viewing ray reaching the joint.

#### Panel 2 — QFN

Show:

- QFN body;
- perimeter terminal(s);
- center thermal/ground pad region underneath the package;
- solder layer under the center pad;
- label `Hidden underside region`;
- optional note `Some edge/toe evidence may be visible`;
- X-ray path passing through the package/board stack to the hidden region.

Do not imply that every QFN solder feature is completely invisible optically.

#### Panel 3 — BGA

Show:

- BGA package body;
- array of solder balls under the package;
- PCB pads;
- label `Hidden solder balls`;
- optical ray stopping at/being blocked by the opaque package body;
- X-ray path through the package to the ball array.

Common X-ray label:
- `X-ray can evaluate hidden joints`

### Required technical relationships

- The exposed leaded solder joint must physically extend outside the package body and be optically visible from a reasonable direction.
- QFN center-pad solder must be under the package body and physically between the package thermal/ground pad and the PCB land.
- QFN perimeter geometry may show an exposed edge/toe indication, but the figure must clearly distinguish that from hidden underside solder.
- BGA solder balls must be under the package, not beside it.
- Optical paths must not be drawn through opaque package bodies.
- X-ray paths may be shown schematically passing through package material to hidden solder interfaces; the drawing should not imply a literal single-ray imaging mechanism or guaranteed defect detectability.
- Do not imply X-ray guarantees complete defect detection or that every hidden-joint package requires 100% X-ray inspection in every production plan.
- Do not label X-ray use as a design failure.
- Do not imply that X-ray is always mandatory for every QFN or every BGA production flow; use wording such as `may require` or `appropriate for hidden joints`.

### Spatial / geometry requirements

- Keep all three package panels on the same PCB baseline.
- Use comparable vertical scale so the hidden/visible contrast is easy to see.
- Use consistent pad/copper/solder colors across all panels.
- Keep the package body opaque.
- Use solid optical rays and dashed/colored X-ray rays with a clear legend or inline labels.
- Ensure hidden solder regions remain visually separated from the package body at 900 px.
- Avoid crowding too many BGA balls; 4–6 representative balls are enough.
- Do not draw an unrealistic center pad floating without contact to the QFN underside.


### Color / style guidance

- Clean engineering-textbook appearance consistent with current EPAC figures.
- White or very light neutral background.
- Flat 2D schematic geometry or restrained cross-section drawing; no photorealism.
- Restrained engineering palette:
  - green/blue-green PCB or solder-mask field;
  - copper/gold conductive features;
  - dark gray component bodies;
  - muted blue/gray inspection or probe geometry;
  - limited red only for a blocked/problem condition when needed.
- Sans-serif labels with enough size for the 900 px mdBook render.
- Consistent line weights and moderate visual hierarchy.
- No decorative gradients, dramatic shadows, glossy rendering, logos, or watermarks.
- Do not rely on color alone; use labels, line style, geometry, symbols, and/or check/X cues.
- Do not embed the external figure number, final caption, or an oversized overall title inside the artwork.


### Scope boundaries

This figure should **not** teach:

- X-ray machine construction;
- CT reconstruction;
- void-percentage acceptance criteria;
- BGA/QFN defect classification;
- detailed solder-joint acceptance;
- reflow process conditions;
- destructive inspection;
- electrical test access;
- probe fixtures.

Figure 3.11.1 owns optical line-of-sight/shadowing. Figure 3.11.3 owns probe/test access.

### Technical-verification basis

Use as technical grounding:

- current Section 3.11.2 text;
- primary Chapter 3 material comparing optical and X-ray inspection;
- technical correction recorded in Section 3.11 internal notes: X-ray need is not automatically evidence of poor DFM;
- current Nordson Test & Inspection AXI guidance identifying BGA and QFN hidden solder joints as legitimate X-ray applications;
- Chapter 4 inspection material for terminology and chapter-boundary consistency;
- approved package terminology already used elsewhere in the book.

### Originality / copyright requirements

Create original simplified package cross-sections.

Do not:

- trace package cross-sections from a textbook;
- copy an X-ray equipment vendor infographic;
- reproduce a manufacturer's package drawing;
- use distinctive BGA/QFN illustrations from online sources.

Use generic, independently drawn package geometry based on standard physical relationships.

### Editable SVG requirements

The strongest final candidate should include a publication PNG and a **true editable SVG**.

The SVG must:

- use vector geometry rather than an embedded raster image as the primary artwork;
- keep text editable where practical;
- keep board features, component bodies, package cross-sections, rays, arrows, probe tips, leaders, labels, and symbols as separate editable objects;
- define explicit `width`, `height`, and `viewBox` values;
- use `preserveAspectRatio="xMidYMid meet"`;
- include an explicit full-canvas white rectangle as the first visible drawing element;
- preserve adequate outer margins so no label, ray, leader, or arrow is clipped;
- use `markerUnits="userSpaceOnUse"` for normal engineering arrows unless there is a specific technical reason not to;
- remain readable when rendered at native size and approximately 1600 px, 1200 px, and 900 px width.

Before recommendation, render-check the final SVG at all four sizes.
