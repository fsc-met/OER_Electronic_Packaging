## Suggested Content for Figure 3.5.1

**Figure title for authoring/reference only:**  
`Component and Board-Edge Spacing`

### Instructional purpose

Show how **component-to-component** and **component-to-board-edge** spacing are physically measured for DFM review.

The figure should help readers distinguish:

- component body versus component manufacturing courtyard;
- component-to-component spacing;
- component/courtyard-to-board-edge spacing;
- edge-to-edge measurement from center-to-center distance.

This figure supports Section 3.5.3 and should make the section's spacing table easier to apply without turning into a numerical rule chart.

### Central teaching message

> **Component-spacing rules are checked between the nearest relevant body or manufacturing-courtyard boundaries, not between component centers.**

A second teaching point is:

> **Component-to-board-edge spacing is an assembly/handling clearance, not a copper-to-edge fabrication rule.**

### Overall layout

- `Component-to-component spacing`
- `Measured edge-to-edge`
- `Manufacturing courtyard`

#### Right panel — Component-to-board-edge spacing

Primary emphasis:

- `Measured to the relevant boundary`

The right panel should make it visually obvious that the board edge is a different reference from another component.

### Required technical relationships

The final figure must correctly show that:

1. Component spacing is measured between the nearest relevant boundaries, not between component centers.
2. A manufacturing courtyard may extend beyond the physical component body.
3. If a rule is defined by courtyard, the dimension arrow must terminate on courtyard boundaries rather than body edges.
4. Component-to-board-edge spacing is a physical assembly/handling rule.
5. Component-to-board-edge spacing must not be visually presented as a copper-to-edge rule.
6. The figure must not imply that one single courtyard size applies to all package types.
7. The figure must not imply that the chapter's representative 0.5 mm, 1.0 mm, 2.0 mm, 2.5 mm, or 3.0 mm values are universal requirements.
8. The figure must not imply that every design requires a visible physical courtyard in CAD; it is a design-rule concept.

### Spatial / geometry requirements

- Use a true top-view representation.
- Keep both panels aligned to the same visual scale where practical.
- Make the manufacturing courtyards visibly larger than the component bodies.
- Use dashed courtyard outlines.
- Keep the spacing arrow perpendicular to the nearest measured edges.
- Do not place dimension arrows through component bodies.
- On the left panel, ensure the measured distance is between the two nearest courtyard boundaries.
- On the right panel, ensure the board edge is a clear straight edge and the dimension arrow terminates at it.
- The board-edge component must remain fully on the PCB.
- If a handling/depanelization zone is shown, keep it secondary and unlabeled with any specific numerical width.
