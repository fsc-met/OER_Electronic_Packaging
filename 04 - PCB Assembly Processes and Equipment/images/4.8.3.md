## Instructional Purpose

Give a first-time Engineering Technology reader a simple operational sequence for setting up a solder-paste printer and responding to the first printed board.

The figure should reinforce the approved beginner workflow:

> **load product/stencil -> verify board support -> align -> establish basic recipe -> print first board -> inspect -> adjust only with evidence**

The reader should clearly understand that inspection creates a **decision point**:

- if the first print is acceptable for the defined inspection step, continue production;
- if the first print is abnormal, check one related physical setup/control, make one evidence-based correction when appropriate, then print and inspect again.

The figure should answer:

> **What should I verify before printing, and what should I do when the first print looks abnormal?**

---

## Central Teaching Message

> **A disciplined printer setup moves from correct tooling and support to alignment, a qualified starting recipe, first-board inspection, and evidence-based adjustment. Do not change multiple settings at once without identifying the related physical cause.**

Supporting ideas:

- setup is a sequence, not random parameter entry;
- the first board is process evidence;
- the abnormal-result path loops back through one related check/correction;
- acceptable evidence leads forward to production.

## Overall Layout

Use a clean **left-to-right main setup flow** with one decision point and one clearly separated feedback branch.

Recommended main path:

1. **Load correct product / stencil / paste**
2. **Verify board support and clamping**
3. **Align using fiducials**
4. **Load qualified starting recipe**
5. **Print first board**
6. **Inspect first print**
7. **Decision: acceptable for next defined step?**

From the decision:

### Normal path

`Yes -> Continue production / proceed to defined inspection process`

### Abnormal path

`No -> Check one related physical cause/control -> Make one evidence-based correction -> Reprint / reinspect`

Then loop back to the inspection decision.

The abnormal branch should be visually subordinate to the main setup path but clearly legible.

## Required Technical Relationships

The final artwork must satisfy all of the following:

1. The process begins with confirming the correct product/tooling/material combination.
2. Board support/clamping is verified before printing.
3. Alignment occurs before the first print.
4. The starting recipe is a **qualified** or approved baseline, not an arbitrary set of values.
5. The first board is printed before any evidence-based adjustment.
6. Inspection occurs after the first print.
7. The decision point has a clearly labeled normal path and abnormal path.
8. The normal path proceeds forward to production / defined inspection.
9. The abnormal path does **not** proceed directly to production.
10. The abnormal path checks one related physical cause/control and then returns for another print/inspection cycle.
11. The figure must not imply changing multiple parameters simultaneously as the preferred method.
12. The figure must not imply that visual inspection alone replaces SPI or later acceptance processes.
13. The figure must not imply that any one symptom proves one root cause.
14. The branch and loop must be visually unambiguous.

## Spatial / Geometry Requirements

- Keep the main sequence on one horizontal row or a simple stepped path.
- Keep the decision point near the end of the main path.
- Route the `Yes` branch forward.
- Route the `No` branch downward or below the main path.
- Return the abnormal branch to `Print first board` or `Inspect first print` through a clear feedback arrow.
- Do not let the feedback arrow pass through unrelated boxes.
- Use arrowheads that clearly terminate at the intended box.
- Keep labels centered with comfortable internal padding.
- Maintain **6–8% outer canvas margin**.
- Use consistent box sizes where practical.
- If the abnormal branch needs more room, expand the canvas vertically rather than compressing the text.
