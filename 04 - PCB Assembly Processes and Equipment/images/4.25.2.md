## Figure Title for Authoring / Reference Only

**First-Board Verification Gates Before Normal Production**

Do **not** place this overall title or figure number inside the artwork.

---

## Instructional Purpose

Show how first-board verification converts an apparently correct setup into physical evidence from the actual assembly process.

The figure should follow one representative first board through:

`printing / SPI`
→
`placement`
→
`reflow`
→
`required initial inspection`

At each stage, students should see a simple gate:

- reasonable/expected evidence -> continue;
- abnormal or uncertain evidence -> hold, correct, and reverify before proceeding.

The figure should make clear that normal production is authorized only after the **required startup evidence** passes. It should also make clear that one successful first board verifies startup readiness but does **not** establish long-term statistical process capability.

---

## Central Teaching Message

> **Check each process at the earliest point where its setup error can be observed, and do not allow a failed gate to disappear into the next process step.**

A second message should remain visually clear:

> **Normal production is authorized only after the required first-board gates pass.**

The figure should preserve the section's broad use of **first board**: one assembly or the defined small initial set required by the local process.

## Overall Layout

Use a **left-to-right first-board process flow** with four major process/evidence stages, one final authorization state, and a common lower hold/correction branch.

Recommended main path:

`First board / defined initial set`
→
`Print + first-print/SPI check`
→
`Placement + first-placement check`
→
`Reflow + recipe/profile applicability check`
→
`Required initial post-reflow inspection`
→
`Normal production authorized`

Each major stage should include a compact evidence gate.

Recommended pass logic:

`PASS / expected evidence`
→ continue to next process stage

Recommended abnormal branch:

`Abnormal / uncertain evidence`
↓
`HOLD`
→
`Correct controlled input / setup`
→
`Repeat affected verification`
→
`Repeat downstream checks invalidated by the change, as required`

A reverify arrow should return to the affected process/evidence stage rather than directly to the next stage.

The same representative board icon may progress through the four stages, visually accumulating paste, placed components, and then soldered joints. Keep this schematic and simple.

## Required Objects and Labels

### 1. First board / defined initial set

Required main label:

- `First board / defined initial set`

Optional small qualifier:

- `startup verification sample`

Recommended visual:

- one generic bare PCB/panel entering the process.

Do not imply that every company always uses exactly one board.

### 2. Print + first-print/SPI gate

Required process label:

- `Print`

Required evidence label:

- `First print / SPI check`

Required representative cues:

- paste on intended pads;
- gross alignment/coverage reasonable;
- `SPI when used`.

Optional small measurement cue:

- `volume / height / area / X-Y offset`

Do not show universal numeric tolerances.

Required pass label:

- `Expected / acceptable startup evidence`

Required abnormal label:

- `Abnormal print / SPI evidence`

The figure should show that a print problem is caught **before placement**.

### 3. Placement + first-placement gate

Required process label:

- `Place`

Required evidence label:

- `First placement check`

Required representative cues:

- `presence`
- `identity`
- `orientation / polarity`
- `gross position`

Optional machine-evidence cue:

- `pickup / feeder alarms`

Do not turn this into detailed placement troubleshooting.

Required abnormal label:

- `Wrong / missing / shifted / misoriented`

The figure should show that a placement problem is caught **before reflow when practical**.

### 4. Reflow + recipe/profile applicability gate

Required process label:

- `Reflow`

Required evidence label:

- `Reflow readiness / profile applicability`

Required supporting cues:

- `correct recipe`
- `oven ready / stable`
- `applicable profile evidence`

Optional small note:

- `profiling may use a representative profiling board`

This note is important if thermocouple/profile imagery is used because the first production board does not necessarily carry thermocouples.

Do not show one universal temperature/time profile.

Required abnormal label:

- `Recipe / profile evidence not applicable or uncertain`

### 5. Required initial post-reflow inspection

Required main label:

- `Initial post-reflow inspection`

Optional representative cues:

- `visual`
- `AOI`
- `X-ray where needed`
- `other defined startup check`

Use no more than two or three cues if space is limited.

Required technical qualifier:

- `method depends on product / process`

Do not show detailed workmanship acceptance criteria.

Required abnormal label:

- `Abnormal startup evidence`

### 6. Normal-production authorization state

Required main label:

- `Normal production authorized`

Required supporting note:

- `required startup gates passed`

Optional small caution:

- `routine process control continues`

Use a restrained green gate/check symbol.

Do not label this as `process capability proven`, `qualification complete`, or `all future boards acceptable`.

### 7. Common hold/correct/reverify branch

Required labels:

- `Abnormal / uncertain evidence`
- `HOLD`
- `Correct controlled input / setup`
- `Repeat affected verification`
- `Repeat invalidated downstream checks as required`

Use a restrained amber/red-orange branch below the main process flow.

The figure should not expand into formal nonconformance disposition or MRB.

## Required Technical Relationships

1. The figure starts only after the line has reached the `Ready for first board` state represented conceptually by Figure 4.25.1.
2. The first board may represent one assembly or a defined small initial set, depending on local procedure.
3. Printing occurs before placement, and first-print/SPI evidence should be checked before the board proceeds to placement.
4. SPI, when used, evaluates product-specific paste-deposit features; the figure must not show one universal percentage or offset limit.
5. A failed/abnormal print gate routes to hold/correction before placement.
6. Placement follows printing, and first-placement evidence should be checked before reflow when practical.
7. The placement gate should focus on identity, presence, orientation/polarity, and gross position rather than statistical placement capability.
8. An abnormal placement gate routes to hold/correction before reflow when practical.
9. The reflow stage must distinguish **machine recipe** from **applicable product/profile verification evidence**.
10. The figure must not imply that every first production board carries thermocouples.
11. The figure may show that profile evidence comes from a representative profiling board or approved prior verification when applicable.
12. The oven must be in the required ready/stable condition before the first board is processed, but oven readiness alone is not product-profile proof.
13. Initial post-reflow inspection occurs after soldering and provides product-specific startup evidence according to the applicable plan.
14. Visual inspection/AOI/X-ray cues are awareness-level only; the figure must not teach detailed Chapter 5 acceptance criteria.
15. `Normal production authorized` occurs only after the required startup gates pass and the authorized local procedure permits continuation.
16. One successful first board does not prove long-term process capability, statistical stability, or future-board acceptance.
17. If a correction changes an upstream controlled input, any downstream verification invalidated by that change must be repeated as required.
18. A failed gate must not disappear into the next process step.
19. If a board has already passed through an unverified/wrong process, it remains controlled for the applicable review/disposition; the figure may imply hold but must not teach Chapter 5 disposition.
20. The figure is a generic manufacturing-readiness model, not one manufacturer's operating procedure or formal aerospace FAI workflow.

## Spatial / Geometry Requirements

- Use one clear left-to-right main process path.
- Place the first-board/initial-set entry at the far left.
- Arrange print, placement, reflow, and post-reflow inspection in physical process order.
- Use one repeated board silhouette or simple evolving board icon to reinforce that the same representative assembly moves through the stages.
- Make the board state change visibly but simply:
  - after print: paste deposits only;
  - after placement: components on printed paste;
  - after reflow: soldered assembly.
- Place each evidence gate adjacent to its process stage, not far below or above.
- Use a consistent pass-arrow direction.
- Place the common hold/correct/reverify branch below the main path.
- Route abnormal branches downward without crossing the main labels.
- Route reverify arrows back to the affected stage or gate, not directly to normal production.
- Keep `Normal production authorized` at the far right and visually distinct from the process stages.
- Keep all text horizontal.
- Use no more than two or three lines in each main process/gate box.
- Use comfortable internal padding.
- Use approximately **5-7% outer margins**.
- If thermocouple/profile cues are shown, keep them clearly separate from the first production board so the figure does not imply thermocouples are always attached to it.
- Do not place pass/fail labels where they can be mistaken for product acceptance criteria.
- Arrowheads must terminate clearly at intended targets.
- No arrows or leaders may cross unrelated text.
- The full composition must remain readable at 900 px.
