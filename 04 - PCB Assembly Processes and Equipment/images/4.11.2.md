# Figure 4.11.2 Suggested Content - One Component Through the Pick-and-Place Cycle

## Status

**Suggested-content specification - Rev1 QA-reviewed candidate**

This file defines the intended instructional content and figure-generation constraints for Figure 4.11.2 in Section 4.11, **Pick-and-Place Machine - How It Works**.

The figure has one instructional role: follow **one component** through the chronological pick-and-place cycle so students can connect the machine subsystems introduced in Figure 4.11.1 to a physical sequence of actions.

Do **not** call this specification or generated artwork canonical/final before explicit project-owner acceptance.

---

## Figure Title for Authoring / Reference Only

**One Component Through the Pick-and-Place Cycle**

Do **not** place this overall title or the figure number inside the artwork.

---

## Instructional Purpose

Give first-time Engineering Technology readers a compact visual sequence showing what happens from board recognition through component placement and release.

The figure should answer:

> **What happens to one component from pickup until it is sitting in solder paste on the PCB?**

It must reinforce the section's operating logic:

> **locate board -> select expected component source -> pick -> inspect/compensate -> move -> rotate -> place/release**

The visual should make clear that the same component is followed through the cycle.

---

## Central Teaching Message

> **A placement cycle combines board recognition, controlled source selection, vacuum pickup, component-position measurement, corrected motion and rotation, and controlled placement/release.**

The machine does not simply move from feeder to board: it uses board and component evidence before final placement.

## Overall Layout

Use a **seven-step numbered process sequence**, preferably arranged as:

- Row 1: Steps 1-4;
- Row 2: Steps 5-7.

Connect the rows with one unmistakable continuation arrow from Step 4 to Step 5. Prefer left-to-right Row 1 followed by a clearly marked continuation into Row 2; do not use a crowded serpentine path if it creates ambiguity.

Recommended step content:

1. **Locate board** - PCB is held; board camera sees a fiducial/reference.
2. **Select expected source** - head moves to the assigned feeder/presentation location.
3. **Pick component** - Z down, nozzle contacts usable pickup surface, vacuum holds part, Z up.
4. **Inspect / compensate** - component-recognition camera measures component X/Y/$\theta$ pickup offset; emphasize measurement/compensation rather than physical recentering.
5. **Move to corrected board location** - X/Y transfer toward the PCB.
6. **Rotate to required orientation** - $\theta$ rotation about nozzle axis.
7. **Place / release / retract** - Z down to solder paste, release, Z up; component remains on paste.

Use one generic SMT component throughout.

## Required Objects and Labels

### Shared visual language

- same generic SMT component in all relevant steps;
- same nozzle/head style in Steps 2-7;
- same PCB/fiducial style where board is shown;
- chronology arrows connecting steps;
- local motion arrows only where needed;
- concise numbered step headings.

### Step 1 - Locate board

Required:

- supported PCB;
- one visible fiducial/reference mark;
- board-recognition camera or sight line;
- label: **Locate board**.

Do not show detailed coordinate-transform geometry.

### Step 2 - Select expected source

Required:

- feeder/presentation source;
- head/nozzle moving to the source;
- label: **Select expected source**.

Do not imply that vision alone verifies exact electrical value or MPN.

### Step 3 - Pick component

Required:

- nozzle directly above component;
- Z-down and Z-up relationship;
- vacuum cue through nozzle;
- label: **Pick by vacuum**.

### Step 4 - Inspect / compensate

Required:

- picked component on nozzle;
- component-recognition camera;
- concise wording such as `pickup X/Y/$\theta$ offset measured` if space permits;
- label: **Inspect / compensate**.

Do **not** show the component physically sliding on the nozzle as the normal centering mechanism.

### Step 5 - Move to corrected location

Required:

- head carrying component toward PCB;
- X/Y motion arrow;
- label: **Move to corrected location**.

### Step 6 - Rotate

Required:

- component on nozzle;
- curved $\theta$ arrow;
- simple orientation target cue;
- label: **Rotate to orientation**.

### Step 7 - Place / release / retract

Required:

- PCB pads with solder paste;
- component contacting the intended paste deposits;
- nozzle above component after release or small Z-up arrow;
- label: **Place, release, retract**.

The component must remain visibly on the paste after nozzle release.

## Required Technical Relationships

1. Board location is established before the final placement location is used.
2. The component source is selected from the active job/setup rather than guessed from visual appearance.
3. The nozzle contacts the component at pickup, vacuum holds it, and the component rises with the nozzle.
4. Component recognition occurs **after pickup** and before final placement.
5. Component recognition measures the picked component's position/orientation relative to the head/nozzle and supports placement compensation; it must not be drawn as guaranteed physical recentering on the nozzle.
6. X/Y motion carries the picked component toward the corrected board position.
7. $\theta$ rotates about the nozzle/component axis.
8. Z motion establishes pickup/placement contact.
9. Placement ends with the component seated on solder paste and the nozzle releasing/retracting.
10. Solder joints must **not** be shown as formed; reflow occurs later.
11. The figure must not imply that machine vision proves exact electrical value or exact manufacturer identity.
12. No universal force, vacuum pressure, pickup delay, or placement delay value should appear.
13. The same component should be recognizable throughout the sequence.
14. Chronology arrows must show process order and be visually distinguishable from local axis-motion arrows.

## Spatial / Geometry Requirements

- Use consistent component/nozzle scale across steps where practical.
- Step numbers must be visually prominent but not oversized.
- Each panel must have enough internal padding that labels do not touch borders.
- Sequence arrows must not cross labels.
- The Step 4 -> Step 5 row continuation must be unmistakable.
- Camera sight line in Step 4 must terminate at the picked component.
- In Step 6, the $\theta$ arrow must clearly wrap around the nozzle/component axis.
- In Step 7, paste deposits must lie under the component terminals/contact regions, not appear as random blobs.
- Step 7 must visually distinguish `component seated in paste` from `solder joint formed`; no fillet or reflowed solder shape is permitted.
- Keep chronology arrows visually different from local motion arrows.
- Maintain about **6-8% outer canvas margin**.
- If seven panels become crowded, increase canvas height or width before reducing text size.

## Technical-Verification Basis

### Section and approved-outline basis

The approved Section 4.11 outline requires the sequence:

> **identify board -> identify component -> pick -> inspect/center -> move -> rotate -> place**

The current Section 4.11 Rev3 clarifies this into a physically defensible cycle in which board recognition establishes the board reference, the active job selects the expected component source, pickup is verified, component position/orientation is measured, and the controller compensates before placement.

### Primary instructional basis

MET406 Chapter 4 - Assembly Technologies, Pick-and-Place Assembly slides 1-22, supports:

- board entry and fiducial recognition;
- feeder/source selection;
- vacuum pickup;
- component vision after pickup;
- correction of pickup X/Y/$\theta$ offsets;
- X/Y transfer;
- theta rotation;
- controlled Z placement;
- vacuum release and continuation.

### Approved secondary/current verification basis

Use the same verification hierarchy already applied to Section 4.11:

- Rao R. Tummala, *Fundamentals of Microsystems Packaging*;
- Clyde F. Coombs Jr., *Printed Circuits Handbook*;
- current manufacturer placement-machine information already used during Section 4.11 verification for architecture and placement-cycle practice.

Do not reproduce a vendor process animation or machine UI.

## Generation Guidance

Preferred method: **controlled vector / SVG-first sequence**.

Recommended workflow:

1. create a consistent generic component and nozzle;
2. create PCB/fiducial and feeder/source objects;
3. build the seven steps in process order;
4. confirm the same component identity/orientation evolution across the sequence;
5. add only the arrows needed for chronology and physical motion;
6. check Step 4 carefully so `inspect / compensate` is not drawn as physical recentering;
7. check Step 7 so the component remains on paste after release and solder is not shown reflowed;
8. render at 900 px;
9. freeze the strongest baseline;
10. make only targeted corrections.

If AI-generated imagery is used for an early concept, reconstruct the technical sequence as controlled vector artwork before publication if arrows, camera relationships, paste geometry, or component continuity are unreliable.
