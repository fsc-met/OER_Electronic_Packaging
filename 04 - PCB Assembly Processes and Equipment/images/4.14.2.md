# Figure 4.14.2 Suggested Content - Basic Lead-Free Reflow Thermal Profile and Key Process Regions

## Status

**Suggested-content specification - Rev1 QA-reviewed candidate**

This file defines the instructional content and figure-generation constraints for Figure 4.14.2 in Section 4.14, **Reflow Oven and Thermal Profile Basics**.

The figure has one instructional role: teach readers how to **read a basic product temperature-versus-time reflow profile** and connect each profile region to the physical soldering process.

Do **not** call this specification or generated artwork canonical/final before explicit project-owner acceptance.

## Figure Title for Authoring / Reference Only

**Basic Lead-Free Reflow Thermal Profile and Key Process Regions**

Do **not** place this overall title or the figure number inside the artwork. The public figure number and caption belong in the Section 4.14 Markdown/HTML block.

## Instructional Purpose

Give first-time Engineering Technology readers one clean profile graph that lets them identify:

- ramp / preheat;
- optional soak / thermal equalization;
- liquidus reference;
- time above liquidus (TAL);
- peak temperature;
- controlled cooling;
- the physical meaning of each region.

The figure should answer:

> **When a product-temperature curve rises and falls during reflow, what do the major parts of that curve mean physically?**

The figure is intentionally a **profile-reading figure**, not a profiling-instrument figure and not a recipe-tuning workflow.

---

## Central Teaching Message

> **The reflow profile is the temperature history experienced by the assembly. Ramp/preheat, optional soak/equalization, the above-liquidus interval, peak temperature, and cooling each control a different part of solder-joint formation.**

Supporting messages:

- the vertical axis is **product temperature**, not oven setpoint;
- the horizontal axis is **time**;
- a soak is process/paste dependent rather than universally mandatory;
- TAL is measured only while the product location is above the defined liquidus reference;
- peak temperature is a local maximum, not the oven's maximum heater setting;
- representative SAC305 numbers provide engineering scale but are not universal acceptance limits;
- supplier/product requirements control the actual process window.

## Overall Layout

Use one dominant **temperature-versus-time plot** occupying approximately 70-80% of the canvas.

Recommended structure:

- vertical axis: `Product temperature (°C)`;
- horizontal axis: `Time`;
- one smooth representative lead-free reflow curve;
- four visually separated functional regions along the curve:
  1. `Ramp / preheat`
  2. `Optional soak / thermal equalization`
  3. `Reflow / peak`
  4. `Controlled cooling`
- horizontal dashed liquidus reference at approximately `217 °C` for the SAC305 example;
- clear TAL bracket spanning the time where the curve is above the liquidus line;
- peak-temperature marker near the top of the curve;
- short physical-process notes below or beside each region.

### Recommended graph logic

The curve should:

1. start near room temperature;
2. rise with a moderate positive slope;
3. optionally flatten/reduce slope through a soak/equalization region;
4. rise through the liquidus reference;
5. reach one clear peak;
6. fall through the liquidus reference;
7. continue downward through controlled cooling.

Do not make the soak perfectly horizontal unless the caption/labels make clear that it is a conceptual equalization region. A shallow positive slope is preferred.

### Small qualification note

Include one concise note in a quiet corner:

`Representative SAC305 process scale; supplier/product limits control.`

This note is important if representative numeric values are shown.

## Required Objects and Labels

### Required axes

- vertical axis with arrow or clear endpoint;
- horizontal axis with arrow or clear endpoint.

Required labels:

- `Product temperature (°C)`
- `Time`

Do not label the vertical axis `Oven temperature` or `Zone setpoint`.

### Required curve and region labels

- one main reflow curve;
- `Ramp / preheat`;
- `Optional soak / thermal equalization`;
- `Reflow / peak`;
- `Controlled cooling`.

### Required liquidus / TAL labels

- dashed or thin horizontal reference line at approximately `217 °C`;
- label equivalent to `SAC305 liquidus reference ≈ 217 °C`;
- two intersection points where the curve crosses that reference;
- bracket, double arrow, or shaded interval between the crossings;
- label `Time above liquidus (TAL)`.

Do not show TAL as the total reflow-cycle duration.

### Required peak label

- point marker at the highest local product temperature;
- label `Peak temperature`.

A small secondary note may state:

`Often about 235-245 °C for many SAC305 paste processes`

Only include this if it remains visually secondary and is paired with the qualification note.

### Required physical-process notes

Keep each to one short phrase or two short lines.

Recommended:

- **Ramp / preheat:** `controlled warm-up • flux begins to activate`
- **Optional soak / equalization:** `thermal equalization • continued flux activity`
- **Reflow / peak:** `solder molten • wetting and joint formation`
- **Cooling:** `solder solidifies • heat removed under control`

Do not include detailed defect lists inside the graph.

## Required Technical Relationships

1. Temperature must rise with time through the early part of the profile and fall after the peak.
2. The soak/equalization region must be shown as **optional/process dependent**, not as a mandatory universal plateau.
3. The liquidus reference must intersect the curve on the rising and falling sides.
4. TAL must span only the interval **between those two liquidus crossings**.
5. The peak marker must occur after the rising liquidus crossing and before the falling crossing.
6. Cooling begins after the peak and continues below the liquidus reference.
7. The curve represents **product temperature**. Do not superimpose oven-zone setpoints as a second primary curve.
8. The figure may use `217 °C` as a representative SAC305 liquidus reference because that value is used in the current section, but it must not imply that every solder alloy uses 217 °C.
9. If `235-245 °C` is shown, label it as a representative current SAC305 paste-process peak range, not a universal requirement.
10. Do not embed the section's entire representative-value table into the graphic. The figure's role is profile interpretation, not table duplication.
11. Do not show thermocouple hardware, a profiler, a profiling board, measurement locations, or formal pass/fail process windows; those belong to Section 4.15.
12. Do not show component-defect examples; Section 4.16 owns integrated SMT-defect troubleshooting.
13. Do not imply that a longer soak or longer TAL is automatically better.
14. Do not imply that faster cooling is always better; show only controlled cooling.

## Spatial / Geometry Requirements

- Keep the graph left-to-right and visually dominant.
- Use clear outer plot margins so labels do not touch the axes or canvas edges.
- Place the liquidus label near the dashed reference line but away from curve intersections.
- Place the TAL bracket directly above or below the above-liquidus segment without crossing the curve.
- Place the peak label with a short leader or point marker.
- Region labels should sit in dedicated bands above or below the curve, not directly on top of it.
- Use light vertical separators or subtle region shading only if they improve reading; do not make the figure look like four physical oven zones.
- If shaded bands are used, label them `profile regions` or use curved-region annotations so they cannot be mistaken for oven chambers.
- Avoid precise equally spaced time ticks unless the figure is intentionally tied to one example. A conceptual time axis is preferred.
- Maintain approximately **6-8% outer margin**.
- The curve should remain smooth and plausible; avoid sharp corners that imply instantaneous product-temperature changes.
- Meaning must remain clear in grayscale through labels, line style, markers, and bracket geometry.

## Technical-Verification Basis

### Current Section 4.14 basis

Section 4.14 Rev3 defines:

- ramp/preheat;
- optional soak/thermal equalization;
- reflow/peak;
- cooling;
- peak temperature;
- TAL;
- a SAC305 liquidus reference of approximately 217 °C;
- representative SAC305 peak/TAL/ramp/cooling scales;
- the important distinction between product temperature and oven-zone setpoints.

### Approved outline basis

The approved Section 4.14 scope specifically requires a **simple temperature-versus-time profile before profiling hardware**, including:

- ramp/preheat;
- soak awareness;
- time above liquidus;
- peak;
- cooling.

### Primary instructional basis

MET406 Chapter 4 reflow material establishes the original teaching sequence:

- staged heating rather than direct heating to peak;
- preheat;
- soak/equalization;
- reflow/peak;
- cooling;
- SAC305 liquidus approximately 217 °C;
- representative TAL/peak/cooling engineering scale.

The public section corrects the lecture's potentially misleading `4 Zones` wording by treating these as **functional profile regions**, not necessarily four physical oven zones.

### Approved reference hierarchy

Technical relationships were checked against:

- Clyde F. Coombs Jr., *Printed Circuits Handbook*, which distinguishes soak-reflow and continuous-ramp lead-free profiles and states that peak temperatures vary with the product;
- Glenn R. Blackwell, *The Electronic Packaging Handbook*, which describes preheat/dry, reflow above liquidus, cooling below liquidus, and the dependence of the product profile on paste chemistry and board thermal mass;
- Rao R. Tummala, *Fundamentals of Microsystems Packaging*, for board-assembly/reflow profile fundamentals.

### Current process-scale verification

MacDermid Alpha **ALPHA OM-340** SAC305 Technical Data Sheet, issue 2024-09-09, checked 2026-09-24, provides a current example of:

- straight-ramp guidance above about 0.7 °C/s and below about 2 °C/s;
- TAL about 45-90 s;
- peak temperature about 235-245 °C;
- cool-down about -1 to -6 °C/s;
- explicit instruction that users should optimize the profile for the actual board application.

The data sheet chart also uses a lead-free above-liquidus reference in the same general SAC305 process context. The Section 4.14 text uses approximately **217 °C** as the common SAC305 liquidus reference.

These values are for **technical verification and engineering scale only**. The figure must not present them as universal acceptance limits.
