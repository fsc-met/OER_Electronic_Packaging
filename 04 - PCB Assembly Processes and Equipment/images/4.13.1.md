# Figure 4.13.1 Suggested Content - Placement Setup Verification Before the First Board

## Status

This file defines the instructional content and figure-generation constraints for Figure 4.13.1 in Section 4.13, **Placement Setup, Changeover, and Common Placement Problems**.

The figure has one instructional role: show the **setup-verification chain that should be satisfied before normal placement production begins**.

## Instructional Purpose

Help first-time Engineering Technology readers see placement setup as a coordinated set of checks rather than as simply loading a program and pressing Start.

The figure should answer:

> **What needs to agree before the placement machine should be released for normal production?**

The figure should connect the major setup evidence already introduced in Sections 4.10-4.12:

- correct job/product/PCB revision/assembly side;
- correct component materials and approved alternatives;
- feeder identity/location;
- nozzle/tool suitability and condition;
- board support and handling;
- fiducial/board-map recognition;
- first-board verification;
- release to normal production only after the evidence agrees.

---

## Central Teaching Message

> **Placement setup is a chain of evidence. The machine should not be released for normal production until the job, physical materials, feeders, tools, board handling, vision references, and first-board result agree.**

Supporting messages:

- software/barcode/interlock verification helps but does not prove that underlying job/BOM/library data are correct;
- a setup mismatch should be corrected before normal production continues;
- the first board is a verification gate, not just the first unit of the run;
- the graphic is a generic verification logic, not a vendor-specific operating procedure.

## Overall Layout

Use a **left-to-right verification flow** with one restrained feedback branch.

Recommended sequence:

1. **Correct job**
2. **Materials + feeders verified**
3. **Nozzle/tool + board support ready**
4. **Fiducials / board map reasonable**
5. **First-board verification**
6. **Release normal production**

A small side note may show that barcode/ID/interlock systems can support the verification chain.

At the **First-board verification** gate:

- **PASS** -> `Release normal production`
- **Mismatch / abnormal evidence** -> `Stop • correct setup • verify again`

The correction branch should return to the verification chain or first-board gate without becoming a complicated troubleshooting flowchart. It must not imply that every mismatch can be corrected without stopping the machine or following the local approved procedure.

### Recommended visual grouping

Use four visual regions:

- **Job definition**: program/product/revision/side;
- **Physical setup**: materials/feeders + nozzle/tools + board support;
- **Machine alignment**: fiducials/board map;
- **Verification/release**: first board -> production.

Use concise text and simple icons rather than long paragraphs.

## Required Objects and Labels

### Required verification boxes

Use labels equivalent to:

- **Correct job**
  - product / job ID
  - PCB revision
  - assembly side

- **Materials + feeders verified**
  - correct part / approved alternate
  - feeder ID/location

- **Nozzle/tool + board support ready**
  - suitable clean tool
  - stable board support

- **Fiducials / board map reasonable**
  - expected references found
  - placements align with intended footprints

- **First-board verification**
  - present
  - oriented
  - reasonably centered
  - no abnormal setup/pick evidence

- **Release normal production**

### Required branch labels

- **PASS**
- **Mismatch / abnormal evidence**
- **Stop • correct setup • verify again**

### Optional support-system note

A small neutral callout, visually outside the required pass path, may say:

`Barcode / feeder / reel / nozzle IDs and software interlocks can support verification`

Do not imply that these systems replace first-board evidence.

## Required Technical Relationships

1. The figure must begin with the **correct active job/product context**, not with component placement.
2. Material identity and feeder mapping must be connected; a correct reel in the wrong mapped feeder is still a setup problem.
3. Nozzle/tool suitability and board support must appear before production release.
4. Board alignment/fiducial evidence must be checked before the first-board release decision.
5. The first-board check must be shown as a gate before normal production.
6. A failed check must lead to **stop/correct/verify again**, not to automatic continuation.
7. The figure must not imply that barcode or feeder-ID verification proves the BOM/library/job data themselves are correct.
8. The figure must not imply one manufacturer's exact setup order; label the flow as generic verification logic through its wording/layout rather than a proprietary procedure.
9. Replenishment and product changeover should not be expanded into separate detailed procedures in this figure.
10. The figure must not include machine-specific offset values, vacuum values, timing values, calibration procedures, or acceptance tolerances.
11. The figure must not drift into line balancing or feeder-layout optimization.
12. Normal production should appear only after the first-board gate passes.

## Spatial / Geometry Requirements

- Keep the primary verification flow horizontal or gently stepped, not serpentine.
- Use one consistent arrow direction for the normal pass path.
- Use a visually distinct but restrained branch for `Mismatch / abnormal evidence`.
- The correction branch must not cross the normal-flow labels.
- Use comfortable internal padding in every box.
- Keep box widths consistent enough to look textbook-like but allow wider boxes for longer concepts.
- Do not place feeder/material icons so close that they look like one physical object.
- If a board icon is used, show it as a simple PCB, not a detailed real assembly.
- If a nozzle/tool icon is used, keep it generic and consistent with Figures 4.10/4.11.
- The first-board gate should use a bordered verification panel rather than a small diamond if a diamond would force text crowding. Content-first readability takes priority over conventional flowchart symbolism.
- Maintain approximately **6-8% outer margin**.
- Keep the correction message in a separate safe region; do not route its arrow through verification boxes.

## Technical-Verification Basis

### Current Section 4.13 basis

Section 4.13 Rev3 states that placement setup requires agreement among:

- job/program;
- materials;
- feeders;
- nozzles/tools;
- board handling/support;
- vision/alignment;
- first-board evidence.

It also states that current production systems may use barcode, feeder-ID, reel-ID, nozzle-ID, and software interlocks, but first-board evidence still matters.

### Approved outline basis

The approved Section 4.13 outline explicitly requires:

- load correct program;
- verify feeders/components;
- nozzle/tool selection;
- board support;
- first-board/setup check;
- feeder replenishment/changeover awareness.

### Primary instructional basis

MET406 Chapter 4 placement material establishes that:

- parts are supplied through feeders;
- the nozzle must successfully pick/retain the part;
- feeder presentation, nozzle condition, vacuum stability, vision, and board position affect placement;
- feeder systems and sensing affect cycle reliability.

### Approved technical verification already documented in Section 4.13

Current JUKI/ASMPT/Yamaha production-setup systems were used during section drafting to verify that modern equipment can use component/reel/feeder identification and setup verification during product setup/changeover/replenishment.

The figure should use only the **generic verified relationship**, not reproduce any vendor interface or workflow graphic.
