# Figure 4.13.3 Suggested Content - Visible Placement Problems Before Reflow

## Status

**Suggested-content specification - Rev2 QA-reviewed candidate**

This file defines the instructional content and figure-generation constraints for Figure 4.13.3 in Section 4.13, **Placement Setup, Changeover, and Common Placement Problems**.

The figure has one instructional role: help students **recognize visible placement-stage observations before reflow without confusing the observation with the root cause**.

Do **not** call this specification or generated artwork canonical/final before explicit project-owner acceptance.

## Figure Title for Authoring / Reference Only

**Visible Placement Problems Before Reflow**

Do **not** place this overall title or figure number inside the artwork.

---

## Instructional Purpose

Help Engineering Technology readers recognize what several common placement observations can look like after placement but **before reflow soldering**.

The figure should answer:

> **What can an acceptable placement, a missing component, a shifted component, a wrong orientation/polarity case, and a dropped/stray component look like before reflow?**

The figure should support the Section 4.13 troubleshooting rule:

> **appearance identifies the observation; machine/material/setup evidence is needed to identify the cause.**

---

## Central Teaching Message

> **Visible placement symptoms are useful evidence, but they do not by themselves prove the root cause.**

Supporting messages:

- an empty footprint is an observation of a missing component, not proof that the feeder failed;
- a shifted component may have several possible placement-stage sources;
- a wrong orientation/polarity case must use a component with a visible orientation reference;
- a dropped/stray component should be shown physically away from its intended placement position;
- no reflowed solder joint should appear because the figure is explicitly **before reflow**.

## Overall Layout

Use **five matched pre-reflow comparison panels**:

1. **Acceptable placement**
2. **Missing component**
3. **Shifted component**
4. **Wrong orientation / polarity**
5. **Dropped / stray component**

Every panel should show the same basic manufacturing context:

- PCB surface;
- copper pads;
- visible solder paste deposits;
- intended placement/footprint area.

The acceptable, missing, shifted, and dropped cases should use the same generic two-terminal chip footprint and the same pad/paste geometry for direct comparison.

The wrong-orientation/polarity panel should use a visibly asymmetric/polarized component, such as:

- a diode with polarity marking;
- a small IC/SOT package with pin-1/reference marker;
- another generic polarized package.

Do not use a visually symmetric resistor to teach polarity.

### Optional bottom note

A single concise banner may state:

`Observation ≠ root cause — check machine, feeder, vision, material, and setup evidence`

This note should be small and not substitute for the public caption.

## Required Objects and Labels

### Shared panel objects

- simplified PCB region;
- two or more copper pads/land features;
- solder paste deposits visibly on pads;
- intended component/footprint region.

### Panel-specific requirements

#### 1. Acceptable placement

- component approximately centered over its intended paste/pad region;
- orientation correct;
- label: **Acceptable placement**

#### 2. Missing component

- footprint/paste visible;
- no component on intended footprint;
- label: **Missing component**

#### 3. Shifted component

- same component visibly offset in X/Y relative to intended footprint;
- offset noticeable but still plausible as a placement problem;
- label: **Shifted component**

#### 4. Wrong orientation / polarity

- asymmetric/polarized component;
- clear pin-1/polarity/reference marker;
- board/footprint reference marker pointing to expected orientation;
- component intentionally rotated or reversed relative to that reference;
- label: **Wrong orientation / polarity**

#### 5. Dropped / stray component

- intended footprint is empty or missing its intended component;
- a loose/stray component is visibly nearby but not aligned to another intended footprint;
- label: **Dropped / stray component**

### Required global note

Use concise wording equivalent to:

**Observation ≠ root cause**

Optional second line:

`Use machine + feeder + vision + material + setup evidence`

## Required Technical Relationships

1. All panels must clearly represent the **pre-reflow** condition.
2. Solder paste should look like deposits on pads, not solidified solder joints.
3. The acceptable panel should establish the visual baseline for comparison.
4. The missing panel must contain no component on the intended footprint.
5. The shifted panel must show a component displaced relative to its intended paste/pad geometry.
6. The wrong-orientation/polarity panel must use a package with visible orientation information.
7. The wrong-orientation case must not be visually ambiguous.
8. The dropped/stray panel must distinguish a dropped component from a deliberately placed nearby component. The stray part must not sit neatly on pads or another footprint.
9. The figure must not label any visual symptom with a single root cause.
10. Do not imply that all shifted components come from feeder/nozzle problems.
11. Do not show tombstoning as a placement-stage observation; tombstoning develops after reflow and belongs in Section 4.16.
12. Do not show solder bridges, wetting defects, solder balls, or reflowed fillets.
13. Do not include a `wrong component value` visual; visually similar component values cannot reliably be identified from appearance alone.
14. The figure must not imply inspection alone proves the electrical identity of the part.

---

## Spatial / Geometry Requirements

- Use identical or closely matched panel dimensions.
- Keep the acceptable/missing/shifted/dropped footprint geometry consistent for direct comparison.
- Draw paste deposits at the same location in those matched panels.
- The shifted component must be displaced enough to see at 900 px but not moved completely away from the footprint.
- In the dropped/stray panel, place the loose component clearly outside the intended footprint with some surrounding whitespace.
- Do not place the stray part so close to another footprint that it looks intentionally placed.
- In the orientation/polarity panel, position the package marking and footprint reference so the mismatch is immediately visible.
- Use leader lines only if needed for the orientation markers; avoid leaders in the other comparison panels. If a footprint reference marker is used, keep it visually fixed while rotating only the component so the orientation error cannot be misread.
- Leave a clear label zone beneath or above each panel.
- Maintain approximately **6-8% outer canvas margin**.

## Technical-Verification Basis

### Current Section 4.13 basis

Section 4.13 Rev3 lists placement-stage observations including:

- missing component;
- shifted/rotated component;
- wrong orientation/polarity;
- dropped component;
- pickup failure;
- wrong component.

It explicitly states that a symptom can have multiple causes and that wrong component identity cannot be proven by package appearance alone.

The current Figure 4.13.3 caption states that several placement problems can be visible before reflow but appearance alone does not identify root cause.

### Approved outline basis

The approved Section 4.13 outline requires awareness of:

- missing component;
- wrong component;
- wrong polarity/orientation;
- shifted component;
- dropped component;
- pickup failure;
- nozzle/feeder issue awareness.

This figure visualizes only the symptoms that can be taught reliably by appearance.

### Primary instructional basis

MET406 Chapter 4 teaches:

- component misalignment as visible center/rotation error relative to pads;
- component missing/drop as an expected part absent from the intended location;
- nozzle/vacuum, feeder presentation, vision, board movement, and component condition as possible placement-stage contributors.

The primary material also teaches tombstoning and lifted leads, but those are intentionally deferred to the integrated post-reflow defect section because their visible final states involve later process stages.

### Technical correction

A `wrong component` is **not** shown as a visual panel because electrical value/part number cannot generally be verified from generic package appearance. The section teaches students to use material/setup evidence for that case.

## Generation Guidance

Preferred method: **controlled vector / SVG-first**.

Recommended workflow:

1. construct one generic PCB/pad/paste footprint baseline;
2. duplicate it for acceptable, missing, shifted, and dropped cases;
3. change only the component state in each duplicate;
4. construct a separate but stylistically matched polarized/asymmetric footprint for the orientation panel;
5. add concise panel labels;
6. add the single observation-versus-root-cause note;
7. render at 900 px;
8. verify that every condition is recognizable without relying on color;
9. freeze the successful visual language and make only targeted corrections.

If AI-generated defect imagery is used for ideation, rebuild the final geometry as controlled vectors.
