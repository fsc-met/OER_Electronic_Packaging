## Instructional Purpose

Teach a beginning Engineering Technology reader that the **location and grouping** of abnormal SPI results often provide more useful process evidence than a single alarm count.

The figure should contrast two spatial patterns:

1. a **regional cluster** of low-volume results;
2. an **isolated low** result surrounded by stable neighboring deposits.

The reader should understand that these patterns suggest different **first checks**, but neither pattern proves one root cause.

The figure should answer:

> **How does where an SPI alarm occurs change what I check first?**

---

## Central Teaching Message

> **SPI board maps are process evidence. A regional cluster suggests checking something common to that region, while one isolated low deposit suggests a more local aperture/release check. The map narrows the first check; it does not prove the root cause.**

Supporting ideas:

- use the same defined reference for comparable features;
- keep “flagged” distinct from “root cause identified”;
- the example window is illustrative only.

## Overall Layout

Use **two side-by-side simplified board maps**.

### Left panel - Regional cluster

Use the exact teaching data from Section 4.9.7:

| Pad location | 1 | 2 | 3 |
|---|---:|---:|---:|
| Row A | 98% | 101% | 97% |
| Row B | 82% | 80% | 81% |

Use a small note:

`Illustrative reference window: 90–110%`

Visually indicate:

- Row A near target;
- all three Row B cells below the illustrative lower limit;
- the three Row B cells form a **regional cluster**.

Concise first-check callout:

`Regional pattern -> check common local support/contact and corresponding stencil apertures first.`

### Right panel - Isolated low result

Use the same 2 × 3 map geometry and same defined reference.

Show five stable cells near target and one isolated low cell. A suitable teaching set is:

| Pad location | 1 | 2 | 3 |
|---|---:|---:|---:|
| Row A | 98% | 101% | 97% |
| Row B | 99% | 82% | 100% |

This right-panel set is an illustration of the current section statement that one isolated low pad with stable neighbors points toward a local aperture/release check.

Concise first-check callout:

`Isolated result -> check that deposit's aperture / local release first.`

### Shared bottom note

`Pattern guides the first check — it does not certify the root cause.`

## Required Technical Relationships

The final artwork must satisfy all of the following:

1. Left panel must preserve the current Section 4.9 numerical example:
   - Row A = 98%, 101%, 97%;
   - Row B = 82%, 80%, 81%.
2. With the stated illustrative 90–110% window, all three Row B values in the left panel are flagged low.
3. The left-panel pattern is a regional cluster, not one isolated alarm.
4. The right panel must contain only one low value while neighboring results remain near target.
5. The regional cluster must be associated with a **common regional first check**, such as local support/contact or corresponding aperture group.
6. The isolated result must be associated with a **local aperture/release first check**.
7. Neither panel may label a root cause as confirmed.
8. The figure must not imply that 90–110% is a universal SPI acceptance window.
9. The figure must not imply that all low-volume patterns have the same cause.
10. The same reference basis should be used within each comparison.

- Use identical map geometry for the two panels.

- Maintain **6–8% outer canvas margin**.
- Keep enough spacing between the two maps that the patterns are visually distinct.
