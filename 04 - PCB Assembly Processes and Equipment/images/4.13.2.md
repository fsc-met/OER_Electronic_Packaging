# Figure 4.13.2 Suggested Content - Placement Accuracy versus Repeatability

## Status

**Suggested-content specification - Rev2 QA-reviewed candidate**

This file defines the instructional content and figure-generation constraints for Figure 4.13.2 in Section 4.13, **Placement Setup, Changeover, and Common Placement Problems**.

The figure has one instructional role: teach the **spatial difference between closeness to the intended target and consistency of repeated placements**.

Do **not** call this specification or generated artwork canonical/final before explicit project-owner acceptance.

---

## Figure Title for Authoring / Reference Only

**Placement Accuracy versus Repeatability**

Do **not** place this overall title or figure number inside the artwork.

---

## Instructional Purpose

Help Engineering Technology readers distinguish two common placement-performance ideas without introducing advanced statistics.

The figure should answer:

> **How can repeated placements be consistent but still wrong, or average near the target but unstable?**

The figure should make visible that:

- systematic bias can produce a tight cluster away from the intended target;
- large scatter can occur even when the average is near the target;
- accuracy and repeatability are related but not interchangeable.

---

## Central Teaching Message

> **Accuracy concerns closeness to the intended placement target; repeatability concerns how tightly repeated placements cluster under the same conditions.**

A particularly important case is:

> **A tight cluster away from the target is repeatable but biased.**

The figure should support, not replace, the Section 4.13 text. It must not imply a product tolerance or machine acceptance criterion.

## Overall Layout

Use a **2 x 2 target/cluster matrix**.

### Column concept - Accuracy / bias

Left column:

**Average near target**

Right column:

**Average offset from target**

### Row concept - Repeatability / scatter

Top row:

**Tight cluster**

Bottom row:

**Wide scatter**

### Four panels

1. **Average near target + tight cluster**
   - best combined condition;
   - dots tightly grouped around the target center.

2. **Average offset + tight cluster**
   - strong repeatability but systematic bias;
   - dots tightly grouped away from target center.

3. **Average near target + wide scatter**
   - average near center but poor repeatability;
   - dots dispersed around the target so the cluster center is near the target.

4. **Average offset + wide scatter**
   - both bias and poor repeatability;
   - dots dispersed and cluster center away from target.

Do not use a dartboard/photo style. Use simplified placement-target geometry.

## Required Technical Relationships

1. The intended target must be identical in all four panels.
2. The number of repeated-placement dots should be approximately the same in all panels.
3. Tight-cluster panels must visibly have smaller scatter than wide-scatter panels.
4. The biased/tight panel must be clearly offset from the target while remaining compact.
5. The average-near-target/wide-scatter panel should be visually centered about the intended target even though individual points are dispersed.
6. The biased/wide-scatter panel should have both a displaced cluster center and large scatter.
7. Do not draw numerical tolerances or acceptance circles.
8. Do not label a single placement as proof of repeatability.
9. Do not introduce Cpk, sigma, process capability, control limits, or SPC.
10. Do not imply that the plotted scatter pattern corresponds to a specific probability distribution.
11. Do not imply that `accuracy` means the same thing as machine resolution.
12. If a mean/centroid marker is shown, distinguish it from individual placement dots and from the intended target.

- Use identical panel sizes.
- Keep target crosshair centered within each panel.
- Use the same target size and dot size in every panel.

- Leave sufficient whitespace between the four panels and between labels and targets.

## Technical-Verification Basis

### Current Section 4.13 basis

Section 4.13 Rev3 defines:

- placement accuracy as how close placement is to the intended target;
- placement repeatability as how tightly repeated placements cluster under the same conditions.

The section explicitly gives two teaching cases:

- a tight cluster about $40\ \mu\text{m}$ to one side of the target is repeatable but biased;
- a wide scatter can have an average close to the target but poor repeatability.

The $40\ \mu\text{m}$ value is conceptual and is **not** an acceptance limit.

### Approved outline basis

The approved Section 4.13 outline requires **accuracy versus repeatability** awareness.

### Primary instructional basis

MET406 Chapter 4 defines:

- accuracy = deviation from true target position;
- repeatability = consistency of repeated placements.

It also identifies mechanical rigidity, motion system, vision, feeder indexing, nozzle/vacuum, board condition, component condition, Z-axis/force, thermal drift, calibration, and maintenance as possible contributors.

### Verification decision

The lecture's fixed machine-category accuracy/repeatability table is **not** reproduced because values depend on machine/head/component/mode/test/statistical definition. The figure therefore teaches only the robust conceptual distinction.

## Generation Guidance

Preferred method: **controlled vector / SVG-first**.

Recommended workflow:

1. construct one target panel;
2. duplicate it into a 2 x 2 grid;
3. keep target geometry identical across all panels;
4. place deterministic dot patterns for the four required cases;
5. add row/column labels;
6. add one concise legend explaining dots/target;
7. render at 900 px;
8. verify that the four cases can be distinguished without reading the caption;
9. freeze the visual language and make only targeted corrections.

Do not use AI-generated scatter points as the final geometry; the dot patterns should be manually controlled. The panel centers should be checked geometrically so the `average near target` panels really do balance about the target.
