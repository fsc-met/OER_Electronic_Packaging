# 4.11 - Pick-and-Place Machine - How It Works

Section 4.10 explained how components reach a repeatable pickup location and how a nozzle holds the part. The next step is to follow that component through the placement machine.

A pick-and-place machine has to coordinate several physical systems at once:

> **hold the PCB -> find the actual board position -> pick the expected component -> recognize its position on the nozzle -> move and rotate it -> place it onto the correct paste deposits**

The machine performs these actions rapidly, but the basic logic is easier to understand when the cycle is separated into a few functions. The goal of this section is to recognize the major machine subsystems and understand how they work together. Detailed placement-data preparation, fiducial correction, and setup troubleshooting are developed in Sections 4.12 and 4.13.

---

## 4.11.1 - What Goes Into and Comes Out of the Machine

A placement machine normally receives four things that have already been prepared:

- a PCB with solder paste printed on the intended pads;
- components supplied through feeders, trays, tubes/sticks, or other presentation devices;
- suitable nozzles or pickup tools;
- an active placement job that tells the machine which component is expected and where it belongs.

The physical output is a **placed PCB**: components are sitting in the solder paste at their intended locations and orientations, but the solder joints have **not** formed yet. Reflow occurs later.

The solder paste provides tack that helps hold components in place after the nozzle releases them. At this point, the machine has completed **placement**, not soldering.

---

## 4.11.2 - Major Subsystems to Recognize

Machine layouts vary by manufacturer and production role, but a modern SMT placement machine usually contains the same functional elements.

| Subsystem | What it does | What a beginning technologist should recognize |
|---|---|---|
| **board conveyor, support, and clamp** | brings the PCB into the machine and holds it in a repeatable, stable position | the board must be supported and stationary enough for accurate recognition and placement |
| **feeder bank / component presentation area** | provides components at known pickup locations | the machine must go to the correct physical source for each expected part |
| **placement head** | carries one or more nozzles and performs pickup/placement motion | the head combines pickup, Z motion, rotation, sensing, and release functions |
| **vacuum nozzle / pickup tool** | holds the component during transfer | the tool must match the usable pickup surface, as discussed in Section 4.10 |
| **X-Y motion system** | moves the head horizontally between feeders, cameras, and board locations | motion may use gantries, beams, linear motors, ball screws, servo drives, or other machine-specific designs |
| **Z axis** | raises and lowers the nozzle for pickup and placement | Z motion establishes pickup contact and controlled component seating |
| **theta ($\theta$) axis** | rotates the component around the nozzle axis | rotation aligns the component with its intended PCB orientation |
| **board camera / fiducial-recognition system** | locates the PCB reference marks and establishes the board's actual position | the machine places relative to the actual board, not only the ideal CAD coordinate system |
| **component-recognition camera** | measures component position and orientation after pickup | pickup offset can be measured and compensated before placement |
| **machine controller** | combines the job data, sensor results, vision corrections, and motion commands | the controller coordinates the complete placement cycle |

Camera architecture is not identical on every machine. A board-recognition camera may be mounted on the moving head or another machine structure. Component recognition may use a fixed upward-looking camera, an on-head scanning camera, or another vision arrangement. The important distinction is **what each camera is looking at**: the board camera establishes the PCB reference, while the component camera establishes the picked component's position and orientation.

## 4.11.3 - The Four Motions to Recognize

For a simplified Cartesian-style machine, four motion directions explain most of the placement action.

| Motion | Meaning | Typical job during placement |
|---|---|---|
| **X** | horizontal motion in one board direction | moves toward the required feeder, camera, or placement coordinate |
| **Y** | horizontal motion perpendicular to X | completes horizontal positioning over the board or component source |
| **Z** | vertical motion | lowers to pick a component, raises for transport, and lowers again for placement |
| **$\theta$** | rotation about the nozzle axis | turns the component to the required orientation |

Some machines move the head while the PCB remains fixed. Other architectures move the PCB, use multiple heads, use rotary/turret mechanisms, or divide the work among parallel placement modules. Those differences change the mechanical implementation, but not the basic requirement: the machine must control the **relative position and orientation between the component and the PCB site**.

A useful practical distinction is:

> **X/Y determine where the component goes, Z establishes pickup and placement contact, and $\theta$ determines how the component is rotated.**

---

## 4.11.4 - Step 1: Bring In and Locate the Board

The PCB enters on the machine conveyor and is stopped, supported, and clamped or otherwise held in the placement area. Mechanical positioning gets the board close to the expected location, but that alone is not enough for fine component placement.

The machine therefore uses a **board-recognition camera** to find fiducial marks or other programmed board references. From those observations, the controller establishes how the actual PCB is positioned relative to the programmed coordinate system.

For this section, the key idea is simple:

> **The program contains ideal placement locations; board recognition tells the machine where those locations actually are on the PCB currently inside the machine.**

The detailed X/Y/rotation correction and the role of global and local fiducials belong in Section 4.12.

---

## 4.11.5 - Step 2: Select and Pick the Expected Component

The active job associates each placement with an expected component source. The placement head moves to the assigned feeder, tray pocket, tube/stick presentation point, or other pickup location introduced in Section 4.10.

A simplified vacuum pickup is:

1. move the nozzle over the programmed pickup position;
2. lower the nozzle in Z;
3. establish contact with the usable pickup surface;
4. apply vacuum;
5. raise the component;
6. verify that the component is being held.

The machine does not necessarily prove the exact electrical value or manufacturer part number merely by looking at the component. Correct material identity depends on the controlled job, feeder/material setup, and verification system. The placement vision system primarily checks the **geometry, position, and orientation** needed for placement.

This distinction matters. A physically similar wrong component can sometimes look acceptable to a placement camera. Material-control and wrong-part-prevention methods are treated later in the chapter.

---

## 4.11.6 - Step 3: Inspect the Picked Component and Establish Its Center

A component is not guaranteed to sit perfectly centered on the nozzle after pickup. Pocket clearance, feeder indexing, component geometry, and pickup position can leave the part slightly shifted or rotated.

The component-recognition system measures the picked part relative to the placement head. Depending on the machine, the component may pass over a fixed camera or be imaged by a camera on the moving head. The controller can determine quantities such as:

- component-center offset in X and Y;
- component rotational offset;
- whether the expected component geometry is present;
- whether the pickup result is within the machine's programmed recognition limits.

The word **centering** can be misleading if it is interpreted as physically sliding every component to the center of the nozzle. Many machines instead **measure the component's actual position on the nozzle and compensate for that offset in the placement motion**.

The important result is that the controller knows where the component is relative to the head before final placement.

---

## 4.11.7 - Step 4: Move, Rotate, Place, and Release

After board recognition and component recognition are complete, the controller combines the programmed placement location with the measured corrections.

The head then:

1. moves in X and Y toward the corrected board location;
2. rotates the component through $\theta$ as required;
3. lowers the component in Z toward the solder-paste deposits;
4. establishes the programmed placement height or controlled seating condition;
5. releases the vacuum or other pickup force;
6. retracts the nozzle and continues to the next component.

The component should contact the intended paste deposits without being dragged across the board or driven unnecessarily hard into the paste. Exact placement height, force, sensing, and timing depend on the machine, component, nozzle, PCB, and qualified process. One universal force or delay value is therefore not appropriate for every placement.

Once released, the component is held mainly by the tack of the solder paste until the PCB reaches reflow.

## 4.11.8 - Placement Speed, Accuracy, Repeatability, and Resolution Are Different

Placement equipment is often described with several performance terms. They should not be treated as interchangeable.

| Term | Practical meaning |
|---|---|
| **resolution** | the smallest motion or measurement increment the system can command or resolve |
| **accuracy** | how close the actual placement is to the intended target under the stated test conditions |
| **repeatability** | how consistently repeated placements return to the same result |
| **placement capability / speed** | how many components the machine can place per unit time under stated conditions, commonly reported as components per hour (CPH) |

A machine can be very repeatable and still have a systematic offset. Likewise, very fine motion resolution does not by itself guarantee equally fine placement accuracy. Board location, component pickup, vision, nozzle condition, mechanical rigidity, calibration, temperature, component geometry, and PCB behavior all contribute to the final result.

### Representative current industrial scale

Current high-speed modular mounters provide a useful sense of scale. Some current manufacturer specifications advertise approximately **50,000 to 120,000 CPH** under defined optimum or benchmark conditions. Published placement-accuracy values for some current high-speed platforms are on the order of approximately **$\pm15$ to $\pm35\ \mu\text{m}$** under the manufacturer's specified test mode and conditions.

For scale:

$$
25\ \mu\text{m} = 0.025\text{ mm}
$$

These numbers are **representative industrial scale, not universal machine requirements**. Vendor specifications use different heads, component sizes, test materials, statistical definitions, production modes, and benchmark conditions. Actual line throughput is normally lower than an ideal CPH rating when feeder travel, component recognition, nozzle changes, board transfer, mixed component types, maintenance, and production interruptions are included.

Do not compare two machines from one CPH number or one accuracy number alone.

---

## 4.11.9 - Why Placement Accuracy Is a System Result

A misplaced component does not automatically mean the X-Y gantry is inaccurate. Final placement depends on a chain of physical and measurement conditions:

> **board location -> component presentation -> pickup -> component recognition -> motion/rotation -> Z placement -> release**

Examples of contributors include:

- PCB support, clamping, and board movement;
- fiducial recognition and board-position correction;
- feeder pickup position;
- nozzle condition and component retention;
- component-center and rotational recognition;
- X-Y-$\theta$ motion calibration;
- PCB warpage or component-height variation;
- placement height/force behavior.

This is why troubleshooting should follow the evidence rather than immediately adjusting global machine coordinates. Section 4.13 develops that troubleshooting process in more detail.

---

## 4.11.10 - What to Watch During One Placement Cycle

A beginning technologist observing a first board should be able to follow one component through the machine and answer:

1. **Board stable?** Did the PCB enter, stop, and remain supported in the placement area?
2. **Board recognized?** Did the machine locate the expected board reference without an obvious recognition alarm?
3. **Correct source?** Did the head move to the expected feeder/presentation location for the programmed part?
4. **Successful pickup?** Was the component retained on the nozzle after Z-up motion?
5. **Component recognized?** Did the vision system accept the picked part and determine its position/orientation?
6. **Motion reasonable?** Did the head move and rotate toward the intended board location without abnormal interference or hesitation?
7. **Placement and release clean?** Did the component contact the paste, release from the nozzle, and remain on the intended footprint?

This is an observation checklist, not a machine-adjustment procedure. If an abnormal condition appears, stop at the appropriate production-control point and use the setup/troubleshooting process developed later rather than changing several machine parameters at once.

---

## Section Takeaway

The main ideas from this section are:

- a pick-and-place machine combines board handling, component supply, a placement head, vacuum/nozzles, vision, and controlled X-Y-Z-$\theta$ motion;
- the board camera establishes where the PCB actually is, while the component-recognition system establishes where the picked part is relative to the placement head;
- a placement cycle can be understood as **locate board -> select expected component -> pick -> inspect/compensate -> move -> rotate -> place/release**;
- component centering may be performed by measuring pickup offset and compensating the placement coordinates rather than physically moving the component on the nozzle;
- after placement, solder paste tack holds the component temporarily; the solder joint forms later during reflow;
- resolution, accuracy, repeatability, and CPH describe different aspects of machine performance;
- placement accuracy is a system result, so one misplaced component does not automatically identify the X-Y motion system as the cause.

Section 4.12 explains the data and alignment side in more detail: **reference designators, X/Y coordinates, rotation, board side, placement data, fiducials, and vision-based correction**.
